## 0. 要約

1. **最初に問うこと。** 今の 3D 問題（v18 の板）で Re を 80 から 3 段（Re_L 250、800、2500）に上げます。そのうえで、Re 80 で登録した差が符号と大きさを保つかを測ります。対象は SCREEN-01 の finalist、手設計 M、FID-01 の tier-A 8 設計です。名前は **RE-01**（Reynolds ladder）とします。
2. **FSAE の Re（約 5e5）は v18 では問いません。** v18 は迎角 20.4°、厚さ 9.4 % の板です。Re ≳ 1e3 では失速した剥離流になる見込みです。定常 RANS はこの種の流れで収束しない（T2-0 の教訓）うえ、この形状には参照データもありません。FSAE の Re は、付着領域の翼を親にする M4（#66）の選択肢 B の側で扱います。
3. **費用と並行性。** WaterLily は Re を上げると 1 対流時間あたりの時間刻みが粗くなり、同じ格子ではむしろ安くなります。高くなるのは、非定常になって平均に長い窓が要る分です。
   - 見込みは R1 が約 7 GPU h と 40〜50 CPU h、R1〜R3 の合計が典型 60 GPU h です。上限は 90 GPU h とします。
   - XV-01（#65）はローカルの CPU（OpenFOAM）を使い、RE-01 の WaterLily は Kaggle の GPU を使うので、並行できます。
4. **手法も変わります。** Re 80 の対差分（同じ位相どうしの差）は、共通乱数（CRN）として placement のばらつきを打ち消すことで σ_d を小さくしていました。この効果は、流れがカオス的になると失われます。そこで σ_d を Re の段ごとに 2 つの推定量で測り直し、互いに突き合わせます。また、カオス的な段で判定できる差は 2〜4 % 程度になり、Re 80 の 0.3 % ではなくなります。
5. **段階。** 進め方は次の 5 段です。M4 の選択肢 B に要る資料（計算なし）は並行して整えます。
   1. Stage 0：parent だけの探索的 probe。差の情報を含みません。
   2. RE-01 の事前登録：PROC-01 の手順どおり、3 観点のレビュー、source review、凍結を経ます。
   3. R1（Re_L 250）。
   4. R1 の判定。
   5. R2（800）と R3（2500）。
6. **M4 への出力。** Re 80 の L1/L2 がこの形状での低 Re の産物かどうかを示します。あわせて、中間の Re で iLES の段階を置く価値と、非定常の統計の契約を渡します。

## 1. 問いと位置づけ

- **今の到達点。** v18 は Re_L = 80（U = 1 m/s、ν = 0.01、L = 0.8 m。翼弦 1.2192 m を基準にすると Re_c = 122）の reduced laminar です。
  - SCREEN-01 は `SCREEN01_GAIN` でした。finalist は +1.077e-2 N（parent の 4.05 %）、drag は −2e-3 N です。
  - FID-01 は `FID01_GO` でした。広いモードの差は、body-fitted な laminar OpenFOAM でも 0.57〜0.77 の割合で残ります。
  - XV-01 は登録中です。
  - これらはすべて Re 80 での主張です。
- **問い（RE-01）。** Re 80 で登録した v18 設計の、同じ位相どうしの downforce と drag の差について、次の 3 点を確かめます。
  1. Re_L 250、800、2500 で符号を保つか。
  2. Re 80 の値に対してどれだけ残るか（retention）。
  3. 設計の順位を保つか。
  崩れる場合は、どの段で崩れるかを特定します。
- **主張の上限**（登録の最初の行に書きます）：
  - 主張できるのは、WaterLily の implicit LES（収束していない格子）における、登録済み v18 設計の差の Re 依存性です。R1 では laminar OpenFOAM でも確かめます。
  - 主張しないもの：物理的な downforce、格子独立性、評価器の GO、FSAE、Re ≥ 1e4、新しい Re で最適化器が選んだ形状。
  - RE-01 の結果が `RE_PERSISTS` でも、高 Re の資格への一歩とは読みません。v18 は付着した FSAE 翼とは物理が違うからです。

### 3.3 位相と比較の基準

- **位相。** 各段で 4 個の新しい in-plane phase を使います。どの段でも同じ phase の組を使い、Re の段どうしの比較も同じ位相どうしで対にします。phase 番号は未使用のものを登録時に確定させます（SCREEN は 11〜16 と 20 を使いました）。
- **Re 80 の基準値。** 登録済みの推定値を使います。finalist と M は SCREEN-01 の phase 13〜16、tier A は FID-01 の phase 7〜10 です。
  - 位相の組が段どうしで違うので、retention は推定値どうしの比になります。
  - 同じ位相での Re 80 の anchor を足すか（flow_32、12 状態、約 6 GPU h）は、plan review で決めます。

### 3.4 統計（非定常への拡張）

- **推定量 A（判定用、M2 から引き継ぐ）。** phase 間の差の SD を σ_d とし、SE_eff = σ_d/√P とします。
- **推定量 B（突き合わせ用）。** run の中の batch means の SE です（20 batch 以上、各 batch は τ_int の 5 倍以上。または Russo & Luchini 2017 の方法）。予測値は σ_d,pred = √(SE_T,design² + SE_T,parent²) です。
- **整合 gate。** σ_d/σ_d,pred が [0.5, 2] の外に出た段は `STAT_INCONSISTENT` とし、判定しません。この比は、CRN の効果がどれだけ残っているかを示す記述量としても報告します。
- **適応的な窓。** burn-in の後、100 CU（対流時間）ずつ延ばします。parent と design の SE_T がともに parent の力の 1.9 % 以下になったら止めます。上限は 800 CU で、上限に達した設計は `UNRESOLVED_STAT` とします。
  - 定常の段（drift 規則を満たす段）では、Re 80 と同じ 120 CU 窓を使います。
  - burn-in の長さは、Stage 0 で後流が発達するまでの時間を測ってから決めます。
- **床。** Re 80 の床 2.09e-4 N は使いません。各段で roll 対照の σ_d を測り、それを床にします（UNC-01 と同じ扱い）。
- **順位。** Re 80 の Δ と各段の Δ の Kendall τ を、10 設計（finalist、M、tier A 8）で計算します。permutation の p 値も付けます。

### 3.5 判定（段ごと、次に全体）

- **段の判定**
  - `RUNG_PASS`：次の 4 条件をすべて満たすとき。
    1. finalist が flow_32 で Re 80 の符号を保ち、|Δ| ≥ 3 SE_eff。
    2. 10 設計のうち、Re 80 の |Δ| が段の分解能（3 SE_eff）以上ある設計の 3/4 以上が符号を保つ。
    3. flow_48 の確認状態（parent、finalist、M、W4）が同じ符号。
    4. τ ≥ 0.6。
    - R1 ではさらに、OpenFOAM V1 で finalist と M が同じ符号で、retention が 0.3〜3.0 であること。
  - `RUNG_BREAK`：finalist の符号が反転し、それが両方の格子で分解されている（|Δ| ≥ 3 SE_eff）とき。または τ < 0.3 のとき。
  - `RUNG_UNRESOLVED`：次の 3 つのどれかにあたるとき。
    - `UNRESOLVED_STAT`：SE の目標に届かない。
    - `RESOLUTION_LIMITED`：flow_32 と flow_48 で finalist の符号が違う、または 2 設計以上で符号が違う。
    - `STAT_INCONSISTENT`：推定量 A と B が整合しない。
- **全体の判定**
  - `RE_PERSISTS`：R1〜R3 がすべて PASS。
  - `RE_BREAKS_AT_k`：最初に BREAK した段が k。
  - `RE_UNRESOLVED`：BREAK はないが、UNRESOLVED がある。
  - `INCOMPLETE`。
- **毎回報告する記述量**
  - 設計ごとの retention 曲線 Δ(Re)/Δ(80)
  - parent の C_L と C_D の Re 依存
  - finalist の drag 制約の挙動
  - Strouhal 数と rms
  - CRN の比
  - run ごとの費用

### 3.6 対照と数値の確認

- **負の対照（roll）と決定性（parent repeat）。** SCREEN と同じに置きます。同じ入力どうしは、カオス的な段でも bit 一致するはずです。
- **格子の整合。** 各段で flow_32 と flow_48 の符号を突き合わせます。
  - 前縁の半径は 2.3〜4.6 セルしかなく、Re_L ≥ 800 ではその境界層が 1 セル未満になります。BDIM の kernel が前縁の剥離をぼかす可能性が高いので、この gate は必須です。
  - flow_64 は、R2 と R3 で parent と finalist についての記述的な裁定に使います。
- **領域の対照（R3）。** 流出までは後縁から 1.6 翼弦しかなく、blockage は 10 % です。流出側を +1 m 延ばした parent の力が 2 % 以上変われば、R3 を「領域に敏感」と記録します。領域を変えるのは新しい登録です。
- **Poisson の probe。** 反復の上限（32）に当たる step が 10 % を超えた場合は報告します。finalist の符号がそれに依存する場合は `UNRESOLVED_NUM` とします。

### 3.7 停止と上限

- 上限は GPU 90 h、CPU 100 h です。1 回だけ書き、延長しません。
- 段の順序は R1 → R2 → R3 で固定します。R4 は、R1〜R3 がすべて判定済み（ラベルは問わない）で、上限にも余りがあるときだけ行います。
- R1 で finalist が両方の WaterLily 格子と OpenFOAM V1 で反転した場合（`RE_BREAKS_AT_1`）は、M4 にとってすでに決定的です。R2 と R3 は任意の記述的な追加とします。
- 力を 1 つ読んだあとは、設計・振幅・格子・窓の上限・閾値を変えません。第 2 の ladder もしません。kernel loss は SCREEN と同じく、原因を問わず同一の再実行を 1 回だけとします。

## 4. Stage 0：parent だけの探索的 probe（`EXPLORATORY_COMMITTED`）

目的は、登録の数値（burn-in、窓、SE の目標、費用、安定性）を推測ではなく実測で決めることです。parent しか計算しないので、設計の差の情報は一切含みません。FID-01 の P0 OpenFOAM probe と同じ扱いです。

- **WaterLily**：parent を Re_L 250、800、2,500 で、flow_32 と flow_48 について 1 phase ずつ計算します。窓は 400 CU です。
  - 加えて、R3 の flow_64 を 1 本計算します。
  - 測るもの：安定性（WaterLily 1.8.0 はこのプロジェクトで Re 80 より上を走らせたことがありません）、drift、rms、τ_int、Strouhal 数、burn-in の長さ、GPU のメモリ、wall、Poisson の反復数。
- **OpenFOAM**：simpleFoam V1 の parent 1 case を Re_L 250 で計算し、収束するかを見ます。収束しなければ、R1 の OpenFOAM は pimpleFoam の記述的な部分集合に落とします。
- **記録**：`docs/exploratory_index.md` に行を足します。力の値は保存しますが、判定には使いません。

Stage 0 の結果を見て Re の段や格子を変える場合は、登録の前に変えます（登録後は変えません）。

| simpleFoam が R1 で収束しない | Stage 0 の V1 parent が収束しない | R1 の OpenFOAM を pimpleFoam の記述的な部分集合にする |
| 「Re 80 はおもちゃだった」という読み過ぎ | — | 主張の上限と §9 の読み方の表を、登録に先に書く |
| GPU の quota を他のセッションと取り合う | XV-01 や別の study と同時期になる | 週の quota の残りを予算記録に書き、push の順序を守る |

## 9. 結果の読み方（M4 への入力、事前に固定）

| RE-01 の結果 | M4 での読み方 |
| --- | --- |
| `RE_PERSISTS` | 固定格子の提案器と対差分の統計は、この形状では creeping flow より上でも転写する。中間 Re の iLES 段階（L2.5）を B5 に置く根拠になり、選択肢 A の論文の頑健性を強める。選択肢 B に付着領域の評価器と検証データが要ることは変わらない |
| `RE_BREAKS_AT_1` または `_2` | Re 80 の finalist の利得は、この形状では低 Re の効果。選択肢 A は L1/L2 を「creeping flow での手順の実証」として書く。選択肢 B に投資する前に、demo 問題を付着領域の親に置き換えることを検討する |
| `RE_BREAKS_AT_3` だけ | 平均として付着している間は転写し、剥離すると崩れる。B5 で運用点を付着領域に制約し、剥離余裕を制約にすることを支持する |
| `RE_UNRESOLVED` | 非定常統計の費用か前縁の解像が律速。B6（backend）と #69 の数値 gate に実測値を渡す |
| `INCOMPLETE` | 保存し、推論しない |
