# GEOM-02 plan (#29): a complete, fail-closed v2 geometry gate bundle on v17

Date: 2026-10-14. Issue: [#29](https://github.com/ramhachi/CFD_opt_sdf/issues/29). Evidence class (target): solver-free contract/capability. No CFD.
Order authority: `docs/phase_plan.md` ("Execution order after LOWDIM-04": #31 done → **#29** → #28 → #25).

## Why, and what "done" means

#29's close condition is: clean analytic fixtures pass, deliberate defect fixtures fail for the correct reason, and a canonical SDF state yields a
**complete** machine-readable gate artifact. The v16 diagnostic (GEOM-01, 2026-10-02) measured 3 gates and left 10 `unmeasured`. The measurement
code mostly exists; the 10 gaps are missing **inputs** (thresholds, a policy that can decide connectivity/events, a mask binding, a physical
domain, the actual zero-level export mesh). Since then #31 registered a research topology policy (limits unresolved), P22-v2 registered the v17
hard count, and the XFID practical STL gate (user decision 2026-10-04) exists. GEOM-02 supplies the inputs, measures every gate on v17, and
closes #29 as a **research gate bundle**, not a manufacturing or FSAE qualification.

Done = (a) every gate has a registered threshold or rule and returns `pass`/`fail` (zero `unmeasured`) on the canonical v17 baseline and on the
LOWDIM-03 parent (as a transition from the baseline); (b) a clean analytic fixture passes all gates; (c) one deliberate defect fixture per gate
fails with that gate's reason and no unrelated gate flips; (d) independent review; (e) record, merge, close #29. A canonical gate `fail` is an
admissible outcome (it is recorded, not tuned away).

## Constraints

- `src/cfd_sdf/design/geometry_gates.py`, `topology_policy.py`, `design/__init__.py` are hashed by frozen LOWDIM closures: **do not edit**. New code
  goes in a new module `src/cfd_sdf/design/geometry_gates_v2.py` that imports and reuses the v1 helpers (`cell_occupancy`, `min_feature_width_m`,
  `min_component_gap_m`, `_gradient_diagnostics`, `_clearances_m`, `surface_gates`, the P20 self-intersection detector), the research policy
  (`topology_policy_research.evaluate_research_transition`) and P22-v2 (`volume_semantics_v2`). No re-implementation of anything that exists.
- Thresholds are fixed in a registered, content-addressed **gate profile** committed before the canonical run. Non-blind: v16 values and the v17
  values in SRCMAP-03a/LOWDIM records are known; the record says so. No threshold changes after the canonical run (a change = new profile).
- Unavailable input ⇒ `unmeasured` ⇒ aggregate fail (v1 semantics kept); `None` is never defaulted.
- Flags stay false; `shape_update_allowed=false`. No physical manufacturing limit is claimed.

## Inputs to register (the actual decisions)

1. **Resolved research policy instance** (#31 record: a resolved instance is a new registration). `minimum_solid_width_m = minimum_void_width_m =
   minimum_gap_m = 2h = 0.05 m` (h = 0.025 m design lattice), labelled **lattice representability limits**: a feature narrower than two lattice
   cells cannot be represented or measured by the lattice width estimator. Explicitly *not* a physical/manufacturing minimum (those remain
   unregistered, and the record says a physical limit would be a further new policy). `max_components` = None (detached allowed);
   source ProblemSpec binding: the v17 genesis/ProblemSpec if one exists, else recorded as absent and the policy carries no source binding.
2. **Policy re-binding view.** v17 states carry `topology_policy_id = "sdf_native_topology_policy_v1"` (part of `state_sha256`, which all CFD
   evidence pins). The bundle must not rewrite stored states. It evaluates topology on a re-bound in-memory copy (same phi and masks,
   `topology_policy_id` = the resolved v2 binding) and records both `state_sha256` values plus the unchanged `phi_fortran_order_sha256`.
3. **Mask binding.** v17 has a 107,415-node design mask and empty fixed/forbidden/root masks. Gate = the research evaluator's mask rules
   (material only in design∪fixed∪root, none in forbidden, fixed/root retained) on the state itself and on the transition. Empty masks are
   reported as empty; the absence of a source ProblemSpec is reported, not inferred.
4. **Distance property:** median `||grad phi|-1|` over the interior narrow band ≤ 0.10 (the value already used as a hard gate in every LOWDIM
   registration).
5. **Zero-level gradient floor:** at every node that has a sign change to a 6-neighbour (the nodes that define the zero level), `|grad phi| ≥ 0.5`
   (central differences, the v1 gradient helper). Rationale: the zero level is locally well defined and its normal is resolvable. The v1 0.05 m
   band bins stay descriptive. Exact-zero nodes count as fluid (P22 convention) for the sign test.
6. **Volume:** P22-v2 `hard_feasible` (N_phi ≤ 8272 on the v17 lattice; representation-specific, not physical volume).
7. **Domain clearance:** physical domain = the registered WaterLily flow domain used by flow_24/flow_32 (the implementer locates its bounds in the
   retained kernel inventories and pins the source path and hash); threshold = 4 flow_24 cells between the solid's cell AABB and every domain face
   (keeps body and boundary conditions separated by more than the solver's stencil). If no flow domain can be pinned, the gate is `unmeasured` and
   the plan is revisited (do not fall back to the SDF array extent).
8. **Actual zero-level export:** reuse the XFID practical STL pipeline (`scripts/build_xfid45_stage_v_input_2026_10_04.py` and its exporter
   `xfid45_round3_export`): extract the state's own zero level at the refinement registered there, remove sub-cell components (< one 25 mm cell)
   and count them, then require watertight, edge- and vertex-link-manifold, positive volume, consistent orientation. **Self-intersection** runs
   the existing P20 detector on that same mesh. If the pipeline cannot extract an arbitrary state (only replays saved Round 3 surfaces), the
   implementer stops and reports; no new exporter is written without a plan amendment.
9. **Topology change:** research evaluator with `allowed_events=()` (OPT-01 #30 is topology-fixed), `birth_qualified=False`. Solid components
   only; the record repeats that cavities/tunnels are not judged.

## Amendment 1 after the adversarial plan review (2026-10-14, before any code)

The review (sonnet subagent, read-only, with read-only measurements on the two canonical states; this makes the plan **more non-blind** and the
record says so) returned SOUND_WITH_REQUIRED_CHANGES. Verified by the planner: P20 detector cap `extraction_qualification.py:292` (12,000
triangles), scikit-image 0.25.2 absent from `.venv`, flow box `julia/CFDSDFWaterLily/src/V16W4Sensitivity.jl:7-9`. These items **replace**
the corresponding items above:

- **A1 Export (item 8).** Use the generic `scripts/xfid45_round3_export.py` `extract(phi, origin, h, r=8)` (Lewiner MC on float64 trilinear
  refinement; r=8 is the 2026-10-04 user decision D3), XFID small-component removal (D2), and `topology()`/`orient` for integrity
  (watertight, edge- and vertex-link-manifold, consistent orientation, positive volume). Mesh volume vs the zero-level volume is informational;
  v1 `surface_gates` is **not** reused (its 1e-6 volume rule against the sharp count volume fails by construction). Precondition: install the
  pinned `scikit-image==0.25.2` into `.venv` (record the command) and require `extract` on the v17 baseline (byte-identical to the XFID
  `canonical_state.npz`) to reproduce the saved XFID baseline surface hash; mismatch ⇒ stop and report.
- **A2 Self-intersection.** New candidate search, reused narrow phase: bin triangles by their refined cube (each MC triangle lies in one
  cube), candidate pairs = same or 26-neighbour cube, excluding pairs that share a vertex only on the shared simplex (reuse
  `_triangle_intersection_contacts` / `_contacts_confined_to_shared_simplex`, vectorized if needed). Mandatory differential test: identical
  verdicts to the unchanged P20 detector on meshes ≤ 12,000 triangles, including a planted intersecting pair. Runtime is recorded.
- **A3 Domain clearance (item 7).** Flow box = `V16W4Sensitivity.jl` `FLOW_ORIGIN_M`/`BASE_MAX_M` (pin path + sha256). Threshold = the
  XFID-registered `stage_v_clearance` value and provenance in `xfid45_round3_export.py` (not a new number). The record states the measured
  margin (v17 ≈ 0.65 m) so the reader sees the gate is far from binding on these states.
- **A4 Zero-level gradient (item 5).** Rule kept: interior sign-change nodes (a 6-neighbour of the opposite sign; exact zero = fluid), central
  differences, `|grad phi| ≥ 0.5`; sign-change nodes on the array boundary are counted separately and make the gate `unmeasured` if any exist.
  **Recorded prediction: FAIL on both canonical states** (review measured 106 of 9,390 and 154 of 8,062 nodes below 0.5, min 1.5e-8). Purpose:
  the shape-derivative normal velocity `-δφ/|∇φ|` is ill-conditioned there; this is a real SDF-quality defect for #25/#28, not tuned away.
  Report the failing nodes' |phi|, location class (exact-zero tie plateau vs thin feature) and count. A fixture shows a 2-cell sheet passes and a
  1-cell sheet / zero plateau fails.
- **A5 Widths and gap (item 1).** 2h was the observed minimum (circular, forbidden by the #31 record). Registered instead, labelled
  **lattice representability limits (research), not physical**: `minimum_solid_width_m = minimum_void_width_m = 1.5h = 0.0375 m`
  (with the v1 h/4 guard: pass ≥ 0.04375, fail < 0.03125), `minimum_gap_m = 2.5h = 0.0625 m` (v1 guard h: fail at a 1-cell gap, pass from 4
  cells, 2–3 cells `unmeasured`). Single-component states: gap gate = `pass` labelled `not_applicable_single_component`. Void width: measured
  on fluid inside the solid's cell AABB padded by one cell; no ridge there ⇒ `pass` labelled `not_applicable_no_enclosed_or_slot_void`; a slot
  fixture must fail. Authority: the 2026-10-13 blanket words, cited as an interpretation (as #31 did).
- **A6 Policy binding (item 2).** No re-bound copies. The bundle calls `evaluate_research_transition` on the stored states with
  `feature_metrics=None` (widths/gap are evaluated by the bundle itself with the resolved instance's limits) and removes **by name only**
  `current_state_policy_hash_mismatch`, `proposed_state_policy_hash_mismatch` and `feature_measurements_missing`, recording the stored legacy
  binding. A test proves every other violation survives the filter.
- **A7 Masks.** On v17 fixed/forbidden/root are empty: the mask gate result carries `vacuous_empty_masks=true`; it is not reported as a
  substantive pass.
- **A8 Structure.** v1 `evaluate_geometry_gates` is monolithic (v1 policy type, no mesh input): v2 reimplements the orchestration and reuses
  helpers only.
