# FD-05 (#37) の solver を使わない診断: 非 plateau の所在

- 実施日: 2026-10-01
- 証拠の区分: **診断のみ**（solver を使わない再解析）。登録済みの判定 T10/T11 FAIL は変えず、criteria・閾値・過去の evidence も書き換えていない。
- 入力:
  - Kaggle kernel `/1` の生の出力（33 本の `*.forces.csv`）
  - FD-05 dataset v2 の摂動 φ raw
  - 結果の正本: [`37_fd05_result.md`](37_fd05_result.md)

## 結論

- FD-05 で plateau にならなかった主因は、流れの非定常性でも時間発展でもない。
- 摂動を ε→0 に近づけても、力がベースラインの値に戻らない。つまり**力がベースライン形状で不連続**である。
- その所在として、次の点を特定した。
  - flow_24 の BDIM band の中に、φ≈0 かつ |∇φ|≈0 のサンプル点が 348 個ある。
  - これらの点では、ε の大きさによらず、どんな摂動でも法線 `n = g/|g|` が最大 180° 反転する。
- 法線の反転が力の不連続の原因だという因果は、まだ仮説である。CFD による確認は済んでいない。

## 1. 力の時系列（`scripts/sdf_native_fd05_force_decomposition.py`）

Evidence: `docs/evidence/sdf_native_fd05_force_decomposition_2026_10.json`（SHA-256 は隣の sidecar に記録）

**流れは完全に定常である。**
- 全 33 本・全成分で、窓内（tU/L 80–120）の標準偏差は最大 2.5e-6 N だった。
- ±ε の差は t=5–20 の時点でもう窓内と同じ値になっていて、差の最大は 1.5e-5 N だった。
- このため、「短時間の計算と発達後の流れの差」や「平均化窓の雑音」で説明することはできない。

**粘性成分は ε に依存しない。** ±ε の差（窓内平均、N）:

| 方向 | ε=0.5 mm | 1 | 2.5 | 5 | 10 |
|---|---|---|---|---|---|
| D1 viscous Fx | 0.00049 | 0.00049 | 0.00049 | 0.00049 | 0.00049 |
| D2 viscous Fx | 0.00078 | 0.00077 | 0.00077 | 0.00076 | 0.00071 |

圧力成分は、ε が大きい側ではおおむね ε に比例する。

**片側差分でも不連続が見える。**
- D1 と D2 では、ε=0.5 mm の +ε と −ε の両方が、ベースラインから粘性抗力で約 −0.002〜−0.003 N、同じ向きにずれる。
  - D1 は +ε で −0.00261 N、−ε で −0.00211 N。
- このずれは ε=10 mm までほとんど変わらない。

**入力と配線に問題はない。**
- 摂動 φ は `base + s·ε·d` と 1e-11 m 以内で一致した。
- Julia の job では、ベースラインと摂動が同じ読み込み経路を通る。

## 2. 法線の診断（`scripts/sdf_native_fd05_normal_census.py`）

Evidence: `docs/evidence/sdf_native_fd05_normal_census_2026_10.json`（SHA-256 は sidecar に記録）

**方法**
- `WaterLilyBody.measure()` / `GridSDFBody.sdf_value_gradient_at_world` と同じ式（トリリニア補間の値と、その解析勾配を正規化したもの）を numpy の float64 で再実装した。
- flow_24 のセル中心と 3 方向の面中心のうち、|d| ≤ 2 flow cell の点で評価した。
- 近似と除外:
  - moving ground は除外した。
  - WaterLily のサンプル位置の半セルのずれは近似している。
  - float32 で計算される GPU の経路とは、丸めの挙動が異なりうる。

**結果**
- band 内のサンプル 38,561 点のうち、ベースラインで |∇φ| < 1e-3 の点は 350 個、そのうち |d| < 1e-6 のものが 348 個だった。|∇φ| の 0.1% 分位は 3.6e-15 である。
- ε=0.5 mm の摂動で法線が 0.1 以上変わる点の数:
  - D1: 312 / 305（+ε / −ε）
  - D2: 316 / 301
  - D0: 98 / 18
- D1 と D2 では、ε=0.5〜2.5 mm の間で、この数も最大変化量 2.0（向きの反転）もほぼ一定だった。滑らかな応答なら、変化量は ε に比例するはずである。
- 反転する点は、ベースラインで |∇φ| ≤ 1e-6 かつ |d| ≤ 4e-7 flow cell の点に限られていた（ε ≤ 1 mm の場合）。
- ε が大きい側（5〜10 mm）では、|∇φ| ≈ 1 の点でも向きの反転が増える。これは格子のステンシルが切り替わる、別種の大きな ε での非線形性とみられる。

## 3. 平坦点の成因（現時点の理解）

**位置**
- 348 点すべてが、v17 の節点平面の 2 枚以上の上に同時に乗っている。内訳は、節点格子の辺の上が 243 点、節点そのものの上が 105 点である。
- 元の STL（watertight）の面は節点平面の上にあるので、面上の節点では φ ≈ 0（|φ| ~ 6e-9）になる。
- flow_24 のサンプルの平面（h = 1/30 m）の一部は、この面の平面と一致する（例: z = −0.15 m）。

**仕組み（1 点だけ確認）**
- 調べた 1 点では、`floor()` が選んだセルは、関係する角がすべて面上（φ≈0）にあるものだった。そのためトリリニア勾配が 0 に潰れる。
- どのセルが選ばれるかは、節点平面のちょうど上での浮動小数点の丸めに依存する。全 348 点を個別に分解してはいない。

**v16 の失敗との関係**
- 仕組みとしては、v16 の FD-04 の失敗（66 セルで勾配≈0）と同じ種類である。h/2 に細かくしたことで数は減ったが、なくなってはいない。
- genesis の census は v17 について「|∇φ|<0.25 のセルが 3 個、判定 `fail`」と記録していた。ただしこれはセル中心での評価なので、流れのサンプル点で起きる今回の縮退は捕まえていない。

**flow 解像度ごとの平坦点の数**（同じ v17 φ、|d| ≤ 2 cell の点のうち |∇φ| < 1e-3 のもの）

| flow | band 内サンプル | 平坦点 |
|---|---|---|
| flow_16 | 16,050 | 377 |
| flow_24 | 38,561 | 350 |
| flow_32 | 76,161 | 0 |

- flow_32 では面とサンプル平面が一致しないため、平坦点は 0 になる。ただし |∇φ| < 0.25 の点は 307 個ある。
- 以前、flow_16 の CPU 短時間計算で ε に比例した結果（`43_result.md`）が得られていた。flow_16 にも平坦点がある以上、この違いは解像度だけでは説明できない。未解決の点として残す。

## 4. 主張できること・できないこと

**主張できる**
- FD-05 の非 plateau は、流れの非定常性でも、摂動入力の誤りでもない。
- flow_24 の band 内に法線が定義できない点が 348 個あり、その法線は ε の大きさによらずに反転する。

**主張できない**
- 法線の反転が力の不連続を起こしているという因果（CFD による確認が必要）。
- 反転点が力の差に寄与する量。
- 修正案の有効性。
- FD oracle や勾配の qualified 化。qualified 関連のフラグはすべて false のままである。

## 5. 次の候補（ユーザー判断が必要。FD-06 は未登録）

1. **法線の正則化**
   - `n = g/|g|` を `g/sqrt(|g|²+τ²)` のように φ について連続な形にする。FD-04 で `TAU=0.1` の試作がある。
   - まず法線の診断で、変化量が ε に比例することを確認する（CPU で数秒）。
   - 次に、短時間の CPU FD で力が連続になることを確認する。
2. **サンプル平面と面の平面の一致を崩す**
   - flow 格子の原点をずらすか、genesis の格子をずらす。
   - ただしこれは primal を変えるので、W3/W4 相当のベースラインを取り直す必要がある。
3. どちらを選ぶにしても、FD-06 は新しい契約として登録する。ε、閾値、判定基準は R5 / FD-05 から変えない。
