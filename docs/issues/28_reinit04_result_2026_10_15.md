## Post-hoc annotations (review findings; the write-once result JSON is unchanged)

- **Export volume sign.** `export_mesh_signed_volume_m3.relative_change` (−2.02 baseline, −1.95 parent) is an orientation artifact: the outputs'
  zero-area faces (25 and 1) make `topology_pass` false, so the XFID `orient` step returns N/A and the raw (always negative) skimage volume is
  reported. Actual magnitudes change +1.8% and −5.2%. The surface-integrity failure itself is real.
- **Mechanism.** The operator inflates distance near the interface (mean |phi| change +0.12h in 0–0.5h, up to +0.25h at 2–3h; seeds come
  from axis-aligned crossings only, `sdf_reinitialization.py:128-137`): output median gradient deviation in |phi_in| < h is 0.10 vs 0.012 on the
  input. The 3h band edge is a separate gradient discontinuity (deviation 0.27 at 2.5–3h vs 0.03 before) that GEOM-02 (band h) does not sample.
- **Surface topology changed, unexplained.** The parent output surface's Euler characteristic goes 2 → −4 and a 0.025 m void width becomes
  measurable, i.e. the sub-cell surface likely gained handles or voids while node/centre component and event gates still pass (they count
  components only). Genus and cause are not confirmed.
- Gradient-floor failing nodes: baseline 106 → 68 (kink 63 → 33), parent 154 → 231 (kink 149 → 169, other 5 → 62; not traced).

## Consequence

- No registered reinitialization operator is usable for a v17 update. Per #30's own dependency text ("reinitialization ready **if** the
  registered update contract includes it"), the first OPT-01 contract **does not include reinitialization**; GEOM-02 `sdf_distance_property`
  (parent 0.0121 vs 0.10) is the trigger that would make one necessary.
- #28 stays open as research, not on the critical path. A next operator would need: sub-cell (not axis-only) seeding or a closest-point
  method, a smooth band blend, and no surface-topology change; it is not designed now.
- All qualification flags remain false; `shape_update_allowed=false`; no claim of a qualified reinitialization or of optimizer descent.
