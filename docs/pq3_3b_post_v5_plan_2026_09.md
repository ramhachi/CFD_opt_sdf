# PQ3.3b v5 停止後の診断と再開計画

Date: 2026-09-23
Status: proposed diagnostic plan; no v6 campaign registered
Authority: [phase_plan.md](phase_plan.md) §11 controls status and execution order.

## 解くべき問題

Stage T の同一 b/q レベルで、実 OpenFOAM のダウンフォースを改善しながら、
投影場 `rho_projection` の体積と設計 mask を守り、b=16 まで到達した候補を
独立に再評価する。現時点では b=8 の収束判定を通過していない。

| 確認済み事実 | 根拠と意味 |
| --- | --- |
| v4 の b=4 は 23 ステップ採択され収束、b=8 は 8 ステップ採択後に Path B の差分が `1e-6` のノイズ閾値未満となり停止 | [v4 outcome](evidence/pq3_3b_campaign_v4_outcome_2026_09.json) |
| v5 は b=8 を 11 採択ステップまで進め、同レベルのダウンフォース係数は `0.579818003757` | [v5 outcome](evidence/pq3_3b_campaign_v5_outcome_2026_09.json) |
| 12 回目は `alpha=1` の実改善が `2.7124e-7 < 1e-6`。小さい alpha の補正後更新は機械精度程度かゼロ | 実更新の採択 gate は正しく停止した。方向の符号検査だけでは採択できない |
| 最後の目的関数変化は `1.0881e-4, 1.0734e-4, 9.7168e-5` | 登録済みの「3 回とも `≤1e-4`」を満たさず、b=8 は未収束 |
| `V(rho_projection)=0.018`、元の上限は `Vmax=0.076325668...` | 0.018 は continuation 上の等式 target。元の不等式制約には約 0.0583 の余裕がある |

実装は `rho - alpha*move*sign(grad J)` を作り、全セルへ一様な
`kappa*move` を加えて投影体積を 0.018 に戻す。停止試行では
`alpha=0.5` と `kappa≈-0.5` がほぼ相殺した。これは**現行提案則の固定点**
を示唆するが、元の体積上限制約下での停留点や KKT 条件を証明しない。
Path B は非ゼロの実更新を最大ノルムで正規化するため、機械精度の更新に
対する有限差分の傾きを、実効的な更新量の証拠に使わない。

## D0 — 停止状態の再構成（OpenFOAM 追加実行なし）

v5 checkpoint、manifest、event、solver summary の SHA-256 を照合し、
入力を固定した別名の診断 artifact を作る。保存済み parent adjoint を
再利用できなければ、その不足を記録して D1 の新規 parent 評価へ送る。
各登録 alpha について、補正前後の `||Δrho||∞` と `||Δrho||₂`、投影場の変化、
`kappa`、提案方向と補正後方向の内積、`grad J·Δrho`、
`grad V·Δrho`、補正前後の投影体積、0/1 にある active セル数、
凍結セル数、mask drift と move-box 違反を記録する。
`grad V` は採用された `DesignTransform` の pullback に従い、
その方向微分を小さな設計空間差分で確認する。

この段階の判定は「体積補正が更新を相殺した」「box-face 凍結が
動かせる方向を除いた」などの**機構の特定**に限る。小さい更新量だけで
物理的・数学的収束を宣言しない。

## D1 — 少数の独立 primal による判別実験

D0 の値を見てから、方向、振幅、最大 solver 評価数、ノイズ判定を
**実行前に immutable manifest へ登録**する。原則として停止点の独立
parent primal 2 回と、下記の方向を各 2 振幅まで、合計 10 回以内の
新規 primal を上限にする。solver case の再利用は parent の再現性評価に
使わない。各評価で solver 収束、`V≤Vmax`、mask、box、目的関数、
ダウンフォース、実更新ノルム、case/hash を記録する。

1. 現行の `alpha=1` 補正後方向を再測定し、改善量が独立 parent の
   ばらつきから判別可能か確かめる。
2. 体積を 0.018 に引き戻さない目的関数方向を測る。元の
   `V≤Vmax` と全 mask/box gate を満たす候補だけ評価する。
3. 体積をほぼ保つ**交換方向**を、目的関数と投影体積の設計空間勾配から
   構成して評価する。線形化で得た方向を最終採択とみなさず、実際の
   非線形投影体積と実 primal で検証する。
4. 0/1 境界から内向きに動く方向が D0 で存在すれば、片側の実行可能
   摂動として測る。中心差分の Path B と同じ資格があるとは扱わない。

元の `1e-6` 改善閾値を、停止後の都合で下げない。判別可能な改善は、
登録済み閾値と独立 parent の再現性評価の双方を超え、二つの振幅で
改善符号が安定し、全物理・幾何制約に適合するものとする。
判別不能・solver 不収束・mask 違反は fail-closed と記録する。
有限個の方向で改善を見つけられなくても KKT 停留とは結論しない。

## D2 — 結果に応じた最小の変更

| D1 の結果 | 次の設計判断 |
| --- | --- |
| 元の上限制約下の方向のみ判別可能に改善 | 等式 target が目的関数更新を阻害した可能性が高い。0.018 は初期形成用 target として扱い、Phase 2 では元の `V≤Vmax` を使う最小変更を検討する。ただし過去の上限のみの運用では疎な非抽出形状になったため、抽出可能性を別 gate として同時に測る |
| 体積交換方向のみ改善 | 一様補正付き符号ステップを、体積感度を用いた可行方向の提案へ置き換える。既存ライブラリを優先し、新しい大規模 optimizer を先に導入しない |
| 境界から内向きの方向のみ改善 | box-face の全面凍結を見直し、片側差分または内点化した方向の資格化を先に行う。未資格の方向を Path B pass と呼ばない |
| いずれも判別不能 | 「測定範囲で改善未確認」と報告し、ノイズ・勾配・設計自由度を再点検する。収束認定や b=16 への自動昇格はしない |

新しい提案則には、補正**後**の実更新ノルムと実 trial 改善の gate を置き、
機械精度の方向を正規化して Path B に渡す前に棄却する。そのノルム閾値は
D0 の浮動小数点誤差と D1 の応答分解能から事前に定める。収束規則を
変更する場合は、採択ステップの小ささと「可行な改善方向がない」ことを
別々に測る。旧 v4/v5 の結果を新規則で遡及して pass にしない。

## D3 — v6 preflight と campaign の入口

D1 で改善方向が見つかった場合だけ、v5 最終 rho、元の設計・投影場、
source grid、solver image、提案則、FD rule、ノイズ閾値、budget、停止条件を
新しい immutable manifest に固定する。v5 の checkpoint は `work/` の
ignored ローカル状態にあるため、再現可能な入力 snapshot と旧チェーンの
hash を別 artifact に保全する。v4/v5 の manifest と結果は上書きしない。

まず b=8 停止点で 1 ステップだけ preflight し、実効更新、FD 方向、
独立 trial 改善、投影体積、mask と solver gate を確認する。次に b=16 への
level 移行と target 復元の 1 ステップを検証する。両方を通過して初めて
長い v6 campaign を開始する。b=8 の出口は新規登録した客観的な規則で
判定し、b=16 は所定の採択数・収束を満たす必要がある。終端 rho では
元の `V≤Vmax` 問題として独立 primal を再評価する。

この終端評価は Stage T 候補の数値資格であり、Stage S の許可ではない。
`rho_projection` からの抽出と PQ4.1 複合 gate、さらに Stage V の
downforce 基準・独立検証は [phase_plan.md](phase_plan.md) の順序に従う。

方法上の参考: 非線形制約の線形化方向は、実際の非線形制約に対する
可行性を別途確かめる必要がある。一般的な最適化理論の参照として
[Torrisi et al., 2016](https://arxiv.org/abs/1610.06834) を挙げるが、
この論文は本 CFD solver や現在の勾配を資格化するものではない。
