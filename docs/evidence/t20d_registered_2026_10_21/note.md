## 判定（凍結した analyzer を 1 回だけ実行）

## Q1 の答え：揺れは「モデルの非定常」ではなく「定常ソルバの収束の問題」
- T2-0c で定常ソルバが落ち着かなかった条件は、xfine30 の h/c 0.09（-1/0°）と 0.134（0/+1°）です。そこでも、同じモデル・メッシュ・スキームの URANS は定常に落ち着きました。ラベルは STEADY_URANS_ONLY です。
  - 研究全体の有効な URANS 58 run はすべて定常に落ち着き、周期的な振動は 1 つもありませんでした。
  - 緩和を強めた SIMPLE（0.3/0.7）でも収束しません。
  - 初期状態を変えても（US1）、同じ値に落ち着きました（h/c 0.134: 1.30846 と 1.30846、h/c 0.09: 1.25863 と 1.25865）。
- **定常計算の見かけの平均は偏っていました。** 落ち着かなかった S0 の平均は、URANS の値より 1.4〜6.2 % 高く出ました。T2-0c の xfine30 で、0.134 と 0.09 の Cl が高めに見えていたのはこのためです。
  - 定常計算が収束したところでも、URANS は S0 より 0.25〜0.91 % 高くなります。PIMPLE と SIMPLEC で、定常解そのものが少し異なります。
- 対照 3 つのうち 2 つが一致の許容 0.5 % を外れたため、`Q1_FORM` は INDETERMINATE です（h/c 0.134、-1° は 0.52 %、fine30 の h/c 0.09、0° は S1 がずれた）。
- h/c 0.09、+1° は、両メッシュ・両時間刻みで遅い過渡のまま窓を終えました（窓内のドリフト 1.3〜4.5 %）。
- 時間刻み: dt と 2dt の差は 0.13〜0.21 % です。h/c 0.134 では dt/2 でも同じ +0.18 % ずつ変わり、時間刻みに対して収束していません（定式化の項によると考えられます）。迎角の微分の変化は 0.5 % です。

## Q2 の答え：G2 は判定できない（入力不良と雑音）
- 時間平均値で見ると、実験曲線に対する平均 |e| は fine30 が 3.0 %（+0.15° で 4.1 %）、xfine30 が 3.4 %（3.8 %）です。
  - fine30: ピークは 0.134 です。
  - xfine30: ピークは 0.179 で、0.134 との差は 0.0008 と雑音帯の中です。
  - xfine30 は fine30 よりすべての高さで低く、差は 0.134 で 7.2 % あります。実験曲線に対しては、0.134 で -5.6 %、0.09 で -8.1 % です。
- 同じ形状を別のメッシュで解いたときの Cl の差（メッシュ実現の雑音）は、h/c 0.134 で σ = 0.020（80 % 上限、12 組）です。雑音帯は 0.056 で、実験曲線自身のピーク余裕 0.022 より大きくなります（`PEAK_NONDIAGNOSTIC`）。この雑音では、ピーク位置の判定は判別できません。
- **`G2_ACTION`: UNDECIDED**（両方のメッシュで入力不良）。登録の §7 のとおり、T2-0b の G2 の行動（壁面解像／LM の評価器研究、または別の検証ケース）が、M4 が決めるまで既定のままです。

## Q3 の答え：xfine30 のピークでは小さな差分を分解できる。ただし細かいメッシュとの整合は未確認で、費用も高い
xfine30 の h/c 0.134 では、次の gate がすべて合格しました。
- G6u: ±0.25° の差 0.040 を雑音 σ 0.00058 で分解できます。d(0.25) 0.080 と d(1) 0.077 も一致します。
- GSu: キャンバー ±0.25 mm の差 0.0095、フラップ 0.030 を分解でき、符号も予想どおりです。
- G8u: ベースメッシュを変えても微分は 6〜8 % しか違いません（T2-0c の fine30 では 26〜29 %）。
- GT134: 時間刻みにも整合します。

ただし fine30 との比較（G3bu）は、値は近い（0.066 と 0.077）ものの、判定できませんでした。fine30 の微分がベースメッシュで 0.066 と 0.088 に分かれるためです。
- 参考として、h/c 0.179 の定常走査（S0 のみ）では、xfine30 は全迎角で収束し、±0.25° を分解できました（fine30 は判定不能）。
