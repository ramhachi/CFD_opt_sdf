1. **P1. The frozen finite pool cannot contain a feasible gain, so P(SCREEN01_GAIN) ≈ 1-3 %** (§3.3, §5.3, §5.5). A feasible gain exists: camber = −A* with a pitch or reflex drag trim, 3.8-4.0 % J (1.4-1.5 g_min) at drag ≤ 0, 3.3-3.5 % (1.22-1.29 g_min) at drag ≤ −m_D. That region is 0.24 % of the 3-D box (0.06 % for ≥ 1.2 g_min). Of the 27 admissible members of rs_pitch_camber_reflex, 17 are drag-feasible and all 17 lose downforce (best −0.37 % J); the positive-downforce members have predicted drag +1.5 to +23 mN. 20,000 perturbed surrogates (±15 % coefficients, random interaction and cubic terms): P(any of the 27 feasible with DF ≥ 0.9 g_min) = 1 %. End-to-end (D-opt design, OLS, in-hull proposals, finalist rule, sealed rule, drag sigma_d 7e-4 N): P(GAIN) = 2.5 % (12 % with a misfit-heavy truth); ~96 % exit as GAIN_BELOW_MIN_AT_SELECTION with the finalist's true DF ≈ −0.5 %; G3's three proposals have predicted DF −0.4 to −1.5 %. R0 is not the limiter (admissible fraction 1.0 still gives 2.5 %). **Change:** one registered, solver-free refinement step after `rs`: the surface's constrained argmax (predicted drag ≤ −m_D) over the box (no hull); a fixed-seed Sobol cloud of 96-128 points within ±0.2 u of it; gate and X1 every point (~2 h on 4 workers); proposals = the best 4-5 admissible by predicted DF; `proposals.json` written once. With this step P(GAIN) ≈ 43 % (71 % with misfit), at ~+0.4 GPU h.
2. **P1. The hull trust region excludes the wedge.** The hull covers 45 % of the box but only 30 % of the feasible-gain wedge (20 % at −m_D); the optimum sits on the camber face, which the D-opt hull touches only near (0, −1, 0). **Change:** "inside the box and within 0.35 u (max-norm) of a design point".
3. **P1. The OC is not end-to-end, and NO_GAIN would be uninterpretable.** The OC draws drag independently of gain (uniform ±2e-3 N); reality is a strict trade-off. "93 % at 1.2 g_min" assumes the best candidate is in the 22; end-to-end ≈ 2.5 %. GAIN_BELOW_MIN_AT_SELECTION looks the same whether the space has no gain or the pool missed it. **Change:** register an end-to-end OC on a visible-data surrogate with the P(outcome) table before freeze; report the fitted constrained optimum in the box; add a secondary label `POOL_LIMITED` (surface predicts ≥ g_min feasible gain but no evaluated candidate reached it).
4. **P2. The optimizer is no better than its own control.** Random 22 gives P(R-best true DF ≥ g_min) ≈ 5 % in the 3-D model vs ≈ 2.5 % for the optimizer; fixed by finding 1.
5. **P2. The ceiling is thin and pinned by an R0 lottery.** MODE-01 v18: camber ±29.3 and ±41.1 fail `min_feature_width` at the native placement while 19.7 passes, so camber A* is a placement lottery and the optimum sits on that face. The lower-bound rule costs ~5 % of g_min (t·SE ≈ 3.5e-4 N); the true threshold for 50 % GAIN is ≈ 1.05-1.15 g_min against a ceiling of 1.22-1.29 g_min. **Change:** allow camber u ∈ [−1.5, 1] (every point gated; ceiling 6.0 % = 2.2 g_min at drag ≤ 0, 5.5 % at −m_D; amplitudes beyond ±19.7 are not OpenFOAM-tested — XV measures them). Optional pitch |u| ≤ 0.5 (the wedge spans pitch −0.55 to +0.24). Constraint alternatives (surrogate): L/D non-decrease alone → corner (1, −1, −1), +24.9 % J, drag +14.8 %, 39 % of the box passes (trivial); L/D plus pitch ≤ 0.7° → corner (0.22, −1, −1), +14.6 % J, drag +7.3 % (no RS needed); drag budget +1 % (2.8e-3 N) → 5.4 % (2.0 g_min), wedge 1.4 % of box, no registered source for the value; +2 % → 6.9 %. Keep allowance 0 and widen the box instead. A pitch = 0 shape-only problem still reaches 3.7 % vs 3.8 %; keep pitch but report the attribution.
6. **P2. Stage 1 and the 10-subset P0 are predictable waste.** Visible ranking pitch 4.2e-2 > reflex 1.5e-2 ≈ camber 1.3e-2 ≫ twist 1.6e-3 ≫ sweep 1e-4 N (third vs fourth 8×). §5.2 ranks by |ΔDF| only (the memo's claim that it picks drag reducers is not what the rule implements). Nine of ten frozen designs will never be used (~576 gated members + X1, 30-40 CPU h); the four twist/sweep axial states cost ~0.9 GPU h. **Change:** fix {pitch, camber, reflex} a priori with the visible-data disclosure and drop the twist/sweep axial states; or compute P0 only for subsets that can occur, with s_m = max(|ΔDF|, 1.4|Δdrag|).
7. **P2. Budget and controls.** Only G2+G3 (3.4 of 18.5 GPU h, 18 %) is search; the random control costs 5.2 h (28 %); in the 96 % branch ~12.5 GPU h is spent for nothing. M (C1) is infeasible by construction. **Change:** run R and M only after a finalist exists (R pool frozen, so still blind; saves ~5 h in the no-finalist case); replace M with a feasible hand design (camber −A* plus a trim sized from the visible ratios by a registered formula).
8. **P2. XV readiness.** For finalists with I_s 2.9-3.4 %, P(OF gain ≥ 1.27 %) ≈ 0.97 with family-central retention (0.65) and b 0.2-0.6 %, only 0.36 with the draft's pessimistic values (0.57, b_22 = 1.04 %). Retention 0.57 belongs to camber +19.7, off the ridge; tier-A retention for pitch/camber/reflex is 0.61-0.68; b_22 assumes 22 exchangeable candidates, near-top competitors number ~3-5 (E[max] ≈ 0.85-1.16). **Change:** report central and pessimistic labels; g_min stays exact. Drag: the ridge cancels camber's +2.0e-3 N against trims of −3 to −4e-3 N; camber's OF drag retention is untested in FID; consider m_D = 1.5e-3 N; add an `XV_DRAG_MARGIN` disclosure. The point-sign finalist filter is fine (a −m_D filter lowers P(GAIN) from 43 % to 30 %).
9. **P2. Reuse for M5 (#33, #40).** The refinement step (surface → argmax → local gated cloud → proposals) is #33's generation update / geometry prescreen; build it as a tested library function (e.g. `propose(surface, box, seed)`); parametrize the analyzer's constants.
10. **P3.** Heave = 0 is right. VIOLATION_UNRESOLVED blocking GAIN is acceptable once finalists sit at −m_D (simulated sealed-drag fail 2-4 %). P0 time should say 30-55 CPU h. A directed ridge design (~10 states, 8-10 GPU h) would also reach XV but supports only a "directed design" claim.

**Verdict:** NEEDS_REDESIGN (minimal). As written P(GAIN) ≈ 1-3 % (12 % worst case); the likely outcome is an uninterpretable pool-limited NO_GAIN after ~12.5 GPU h. Minimal redesign: keep G1/G2/G3/F/A, g_min, the sealed rules, D, R3, phases and budget; add the post-G2 gated refinement cloud with box clipping instead of the hull; fix the subset a priori and cut the nine unused P0 subsets and the twist/sweep axial states; make R and M conditional on a finalist with a feasible hand-built M; register an end-to-end OC and a POOL_LIMITED label; optionally extend camber to u ≥ −1.5. Effect: simulated P(GAIN) ≈ 45-70 %, XV downforce pass 0.4-0.95 depending on retention assumptions; with these fixes GO.
