### 1.1 The viability rule (in the Stage-0 charter, before any Stage-0 run)

Inputs per candidate rung k, parent only, flow_32, three phases that are not registered RE-01 phases, 800 CU total (R1: 240 CU), plus one flow_48 parent run of 400 CU at 800 and 2500:
1. Burn-in B_k: first 100-CU block whose block mean is within the block-mean SE of the following blocks (block-mean stationarity rule); B_k >= 80 CU.
2. Regime: steady if the UNC-01 half-window drift rule passes and the batch-means SE over the last 40 CU is below 0.1 % of the parent force in all three phases; otherwise unsteady. (Periodic is a sub-case of unsteady here; no separate rule.)
3. S0_k: batch-means estimate of the zero-frequency spectral density of lift at block lengths 5, 10, 20, 40, 80 CU over the post-burn-in window (plateau of block length x block-mean variance), 90 % upper bound; cross-checked against the between-phase SD of the three parent time means (if that SD exceeds 2 sqrt(S0_k / W_used), S0_k is replaced by the larger value implied by it: one-sided, conservative).
4. Window: W_k = smallest multiple of 100 CU with sqrt(S0_k / W_k) <= 1.5 % of the parent force (steady regime: W_k = 40, Re-80 machinery, estimator A only).
5. Cost: C_k = cost of the registered run table at B_k + W_k with the measured steps per CU.
6. Manipulation precondition: the parent's C_L or C_D at rung k differs from the previous rung's (Re 80 for R1) by more than 3 x the combined Stage-0 SE; a rung that fails it is NO_RE_EFFECT already and is dropped.
7. Numerics: no divergence, non-finite force or Poisson cap fraction above 1 % in any Stage-0 run at that rung; Poisson residual quantiles recorded.

A candidate is **formal** iff W_k <= 400 CU, C_k <= its cap, the cumulative formal cost (R1 + formal rungs already selected in priority order) <= 65 GPU h, and items 6-7 hold. Selection: R1; then 800 if formal; else 450 if formal; then 2500 if formal and at most two unsteady rungs are already chosen. Any candidate not selected gets the pre-declared descriptive probe (section 1 cost table) only if the remainder allows; otherwise it is `NOT_RUN`. The registration records the Stage-0 numbers, the selected rungs, W_k and C_k; after it no rung, grid, window or threshold changes (drop-only triggers: divergence, memory, wall, budget record).

Thresholds in the charter (not derived from Stage 0): 0.3 band, 1.5 % target, 400 CU, the caps, the regime rule constants, the run table.

## 3. The 2D same-mode cross-Re bridge (strategy S8b)

**Decision:** Worth doing, with WaterLily 2D (GPU), not OpenFOAM 2D laminar; but not in this plan's execution window by default. Prepare it now as a second exploratory track ("BRIDGE-2D-00") with a written charter and the 2D section/morph code (paper and code only, no GPU) in weeks 2-3, cap 15 GPU h, and run it before M4 only on one of two triggers: (a) the viability rule drops the first unsteady rung (which frees 18-29 GPU h in week 3-4), or (b) week-4 quota remains after the first unsteady rung. Otherwise it is handed to M4 as a prepared candidate that M4 can start on day one of option B.

**Why worth it.** It is the only cheap measurement in reach that touches the target Re: T2-0c has pitch, camber (parabolic) and trailing-edge flap morph responses on the Tyrrell 026 section at Re_c 4.6e5, h/c 0.224, fine30, every gate passed (sigma_eff 0.00043, +-0.25 deg resolved, derivative consistent with xfine30), descriptive. The same three levers are v18's pitch, camber and reflex. The bridge asks whether a WaterLily low-Re proposer's slope signs and ratios on an attached section predict the high-Re RANS slopes across 1.5-2.5 decades: option B's central risk, which no RE-01 rung can test. Cost [calc]: a 2D grid of about 1600 x 600 (0.96 M cells, 400 cells per chord), about 250 steps per CU, 200 CU: 0.31 h per run; 7 states (parent, +-pitch, +-camber, +-flap) x 3 Re (1e3, 3e3, 1e4) x 2 grids = 42 runs = 13 GPU h.

**Why WaterLily 2D.** The question is about WaterLily as a proposer; a second low-Re solver adds a cross-check, not the answer. OpenFOAM 2D laminar would need a wall-resolved low-Re mesh family (the T2-0 family has a fixed 0.6 mm first layer sized for wall functions at 4.6e5), and LOCAL-OF-01 found the gmsh pipeline `LOCAL_ENV_FAIL` (meshes of rotated geometries differ by platform, run-to-run numbering variants), so it would run on Kaggle CPU with hash-pinned meshes: a new mesh path on the CPU slots XV-01 does not use, but 1-2 weeks of engineering. Keep it as an optional follow-up if the WaterLily slopes disagree in sign with T2-0c.

**Why not inside RE-01 and not before the parent scan.** Different body, different question, different claim ceiling; mixing it into RE-01 would widen the registration. Its engineering is larger than the scan's (a 2D WaterLily job does not exist in the repo; the section SDF from `data/t20/tyrrell026s_genua2009.dat` through `scripts/t20_case.py:airfoil_points`, the three morphs as SDF deformations, a moving ground at h/c 0.224, a chord-resolution check), and its comparison target carries RANS model-form spread (SA vs SST 33 % on incidence derivatives, G2 failed on every level). Its result matters once M4 picks B; the scan's result matters for which branch M4 picks.

## 6. Three corrections to the adopted fixes

1. **Secondary designs "judged by sign only" are nearly unpowered at unsteady rungs.** One-sided sign resolution of a single design (P = 4, t_3) at retention 0.5: finalist 0.70 / 0.20 / 0.10 at SE_T 1.0 / 1.9 / 2.7 %; M 0.38 / 0.10 / 0.06; R-best 0.21 / 0.06 / 0.04 [calc]. At the viability target (1.5 %) the finalist's sign is resolved with probability about 0.4 at r = 0.5. State this in the registration's power note, and add one descriptive quantity: the finalist's residual from the tier-A slope, Delta_fin(Re) - b_k Delta_fin(80), in units of its SE. It tests whether the selected design behaves like the unselected set (the selection-bias question of governance G6) and is informative even when the sign is not resolved. No label hangs on it.
2. **flow_48 confirmation should not carry the finalist.** With 2 phases its 4 % effect is unresolvable on flow_48 at an unsteady rung; the grid gate is better served by the two largest unselected effects (C4, reflex -29.3) and the slope ratio b_48 / b_32 (section 1.2). The finalist's flow_48 value, if wanted, is descriptive.
3. **The R1-OF shift set.** Use FID's Halton 49-64 for the tier-A cases at Re 250 so that each OpenFOAM retention ratio is same-shift paired with its Re-80 value (the OpenFOAM analogue of same-phase pairing); XV-01 uses 81-96, so there is no collision. The adoption text says "fresh shifts" nowhere, but the registration should say which, and why same-shift is chosen.
