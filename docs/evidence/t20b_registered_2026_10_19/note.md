## ラベル（判定は変えない）
- fine30 は平均 \|e\| 2.90 % で、Cl の最大は 0.134 にある。med30 より実験に近い。
- T2-0a と同じ 5 車高は全桁で一致した。同じ形状ではメッシュの SHA-256 も一致した（T2-0a、W、L の 3 回）。陰性対照の \|ΔCl\| = 0 はパイプラインが決定的であることを示すだけで、ノイズの大きさは測っていない。差分に効くノイズは迎角を変えたときの再メッシュによる跳びで、σ_mesh は Cl の 0.17 %（0.224）と 0.35 %（0.134）。
- LM（wr2、LM を 12000 反復）は `LM_DATA_AGREES`。サイクル平均は平均 \|e\| 4.77 % で、最大は 0.134。ただし 0.134 と 0.09 では Cl の振動の標準偏差が 8〜9 % ある。1 ケース約 3.5 時間。
- adjoint（adjointOptimisationFoam、乱流は凍結、壁関数）は `ADJ_FAILED`。primal は収束した（残差 1e-5 以下）が、adjoint は 1322 反復目に pa の GAMG で SIGFPE が出た。微分ファイルは出ていない。この判定は今回の実装についてのもの。
- DAFoam は試していない（R5、#23、#66 による）。抗力は実験と比較していない（Genua の CFD より 18〜35 % 小さい）。

## 次の行動（登録時に決めていた表のとおり）
- G2 が不合格なので、高 Re の評価器を使う前に、壁面解像（または遷移 LM）の評価器研究か、別の検証ケースが要る。
- G3b と G6 が不合格なので、再利用の前に、メッシュ系列と再メッシュ雑音の研究（再メッシュをやめて、トポロジーを固定したモーフィングにする）が要る。
- #66 項目 1（高 Re 評価器の採用）については、登録済みの go/no-go が NO-GO になった。この根拠では採用できない。
