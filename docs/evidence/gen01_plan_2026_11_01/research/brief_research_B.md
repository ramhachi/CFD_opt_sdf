# Brief B: generic parameterisation, regularisation, level sets, topology, constraints (web research)

Use WebSearch (mode "extended" where results are thin) and WebFetch. Do not write files; return a report (~2000 words, tables preferred, every claim cited: DOI/venue/year or URL + access date). Today is 2026-11-01. Say "unverified" where you cannot verify.

Context: a research project wants a GENERIC whole-vehicle (FSAE race car: wings, sidepods, floor, body, suspension arms) aerodynamic shape/topology optimizer. Geometry is a signed distance field (SDF) on a fixed grid (the SDF is the representation and the constraint language: union of components, envelope/packaging, clearance to ground and wheels, minimum thickness). Gradients will come from an adjoint RANS solver on body-fitted meshes generated from the SDF. Earlier, using raw SDF node values as design variables on a fixed grid failed: sub-cell shape changes became discrete "cell switching" events, and automatic differentiation of the unsteady immersed-boundary solver diverged. The project therefore wants design variables that are a regularized smooth field (not per-component hand parameterisation), with hundreds to thousands of variables.

Questions:
1. Node-based shape optimization with regularization in industrial aero: Vertex Morphing (Hojjat, Stavropoulou, Bletzinger 2014; Bletzinger 2014 "A consistent frame for sensitivity filtering"; Kratos ShapeOpt), Sobolev / H1 gradient smoothing (Jameson; Schmidt & Schulz; Allaire–Dapogny–Jouve 2021), filter radius vs mesh size rules, how curvature/feature size is controlled, whole-car applications (BMW, Audi, VW, Toyota papers 2014-2026), convergence behaviour, typical number of iterations and gains reported (drag/downforce %).
2. Level-set / SDF shape and topology optimization with adjoint RANS at high Re: Hamilton–Jacobi advection with velocity extension, reinitialisation, "SDF as representation but smooth variables" precedents (Yamasaki 2010; Kreissl–Pingen–Maute 2011; Yaji 2014; RBF level set Wang & Wang 2006; Vertex-Morphing-like filtered level sets), CutFEM/XFEM fluid TO (Villanueva & Maute 2017; Burman et al.), hole seeding / topological derivative in fluids (Høghøj, Andreasen, Maute 2025 and earlier), Brinkman/porosity transfer failures (Theulings 2023; Alexandersen 2022), minimum thickness / feature size via SDF offsets (Allaire–Jouve–Michailidis 2016), and multi-component packaging constraints in level-set form.
3. Remeshing versus mesh deformation when the level set moves: body-fitted remeshing each iteration (snappyHexMesh / cfMesh / pointwise automation), mesh-morphing (RBF, Laplacian, linear elasticity) limits, "mesh noise" in the objective between remeshes and its effect on gradient-based optimisation (how practitioners handle it: fixed background mesh + consistent refinement, GCI-style noise floors, trust-region with noise), and immersed/level-set-on-background-mesh alternatives (e.g., level-set + CutFEM in Nektar++/FEniCS, XFEM).
4. Multi-component vehicle aero optimisation in the literature: whole-car adjoint cases (DrivAer, Ahmed body, F1/FSAE), handling of rotating wheels and moving ground, symmetry, constraints (lift balance, drag, packaging, rules boxes), multi-objective (downforce vs drag, aero balance), and what has been experimentally validated.
5. Surrogate/derivative-free alternatives that scale to ~100-1000 variables (active subspaces, Bayesian optimisation with GPs in high dimension, SPSA, evolution strategies, trust-region DFO such as DFO-LS / Py-BOBYQA, physics-informed surrogates / neural operators for cars 2024-2026) and the evaluation counts they need, as a comparison baseline to adjoint.
