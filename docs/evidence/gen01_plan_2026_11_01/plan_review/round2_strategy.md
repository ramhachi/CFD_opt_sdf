# GEN-01 plan rev 1 (7937d12d, SHA-256 a7b74235...0cbf0ce), round-2 review, angle R-S (strategy, physics, validation)

(Opus reviewer, 2026-11-01, verbatim.)

**Verdict: GO_AFTER_FIXES.** Rev 1 now says plainly in §0 what the main line is, and it carries out most of S1-S16 faithfully. Three P1 items must still be fixed before ADJ-00b is registered: the change of representation has not been put to the user, and it conflicts with the project goal in STATE; the capability matrix has no effect on the toolchain selection, and it leaves a loophole that allows FFD; the toolchain is chosen before the transition model is.

**Does it still answer the request?** Plainly, no on the SDF part. The main line has become a conventional industrial adjoint programme: BMW-style Vertex Morphing with a DAFoam discrete adjoint. That is defensible engineering, and the architecture is generic. But it no longer justifies choosing the SDF. The genericity now comes from node-based Vertex Morphing, not from the SDF. The SDF is reduced to a tool for evaluating constraints, plus a topology track (TOPO-G) off the main path with no precedent. §3.11 tests whether Vertex Morphing is generic, not whether the SDF is. §1.3's closing sentence overclaims. The whole vehicle is reached only in the last and most uncertain stage (CAR-01), and the suspension arms have been quietly dropped.

## Findings

**R-S1 (P1). §0, §1.3 last paragraph, §10 item 2, §11.** STATE's goal line says "A canonical-SDF rigid-object shape/topology optimizer"; §1.3 makes the explicit surface the canonical design instead. §11 lists "SDF は制約とトポロジーの言語" under 決めたこと, not under the user items; S7 asked for both. The user's stated reason for the SDF is the premise this plan reverses. §10's writing list does not amend the goal line. Fix: add a §11 user item ("Accept that the canonical design is the explicit surface; the SDF is used for constraints and topology; genericity comes from node-based variables"); add the STATE goal-line and phase_plan goal amendment to §10; rewrite the closing sentence of §1.3. Confidence high.

**R-S2 (P1). §4.2, §4.3: the capability matrix does nothing, and the FFD loophole lets the plan drift.** The capability items sit in the exploratory ADJ-00a; the §4.3 selection table ignores them; a candidate with no rotating-wall adjoint could win the wing stages and fail at WW-01. "節点変数＋フィルタ（または FFD 経由の等価物）" accepts FFD; DAFoam's documented route is FFD and its node route undocumented; accepting FFD lets the main line slide into per-component FFD boxes, which the user rejected. The tie-break "メモリ×時間が最小" uses ADJ-00a's exploratory measurements to make a selection (the G1 defect again). Fix: move the matrix into ADJ-00b as pass/fail requirements indexed by stage (wing; WW adds rotating wall and moving ground; CAR adds porous zones); define the node-based pass as dJ/dX on the CFD wall nodes exported and chained through the project's T^T and filter^T with the dot-product test; an FFD-only result takes the fallback-branch label; re-measure memory and time inside ADJ-00b, or fix the tie-break formula before any ADJ-00a run. Confidence high.

**R-S3 (P1). §3.8, §4.3, §6.3: the transition model is chosen after the toolchain.** ADJ-00b selects the toolchain on SA/SST before M4; EVAL-3D-01 after M4 selects the optimising model, possibly a transition model. DAFoam's model directory has kOmegaSSTLM but no k-kL-omega. If EVAL-3D-01 picks a model with no adjoint, the optimiser runs a model that was not validated or uses a frozen-transition adjoint, untested where the separation bubble moves. Fix (pick one, before ADJ-00b): (a) register in ADJ-00b the set of models usable for optimisation (must have an adjoint) and restrict EVAL-3D-01's candidates to that set; (b) register "optimise fully turbulent; transition for verification only" and accept that claim ceiling. Under either, put the frozen-transition gradient through the §3.4 contract at the parent. Run the S1223 2D discrimination before ADJ-00b (primal-only, local CPU, methodology ceiling). Confidence medium-high.

**R-S4 (P2, blocks the WING-3D-01 registration). §3.11, §6.4: the genericity criterion cannot fail as written.** IFW is already used in ADJ-00 case (4), EVAL-3D-01 and as the public replication case; it will not be held out; same class as the first target; "通る" undefined; a genericity failure would void an aerodynamic PASS and the reverse. Fix: freeze by hash a second geometry no earlier stage has seen, preferably a different class (DrivAerML bodywork, or a team sidepod or nose); define the pass (identical code SHA, only ProblemSpec and CAD differ; GEOM-K1 gates and checkMesh pass; primal converges with a certificate; weak condition holds at the parent; >= 3 steps accepted); report hand-set ProblemSpec fields and CAD clean-up hours; own label GENERICITY_PASS / GENERICITY_FAIL with the code diff recorded. Confidence high.

**R-S5 (P2). §6.3: EVAL-3D-01 is gated on the wrong physics.** The first target is an isolated rear wing out of ground effect, yet EVAL-3D-01 gates it on IFW data (front wing in ground effect, h/c 0.36); an IFW failure would send the programme back to M4. "S1223 の失速角の順序" is undefined; stall is RANS's worst-predicted quantity and the design is constrained to attached flow. "At least one model set passes" against bands not yet fixed invites forking paths. "ADJ-00 と並行可" contradicts the M4 gate. Fix: split: EVAL-3D-01a: S1223 Cl(alpha) and Cd(alpha) before stall, the laminar separation bubble and drag at Re 1-3e5, gates WING-3D-01; EVAL-3D-01b: IFW vortex path and separation line, gates WW-00/01; bands from measurement uncertainty only; delete "並行可" or limit it to preparing the registration. Confidence high.

**R-S6 (P2). §6.4: the rear wing is optimised isolated, but "trends good" is from an installed wing (Pacheco).** VAL-X also needs a prediction for the installed wing. Fix: installed check: half-car parent with parent wing and with final wing, about 8 mesh realisations each (one primal ~690 core-h, ~30 USD); require retention >= 0.5. Confidence medium-high.

**R-S7 (P2). §6.5: WW-00.** (i) "探索的＋登録の計測" repeats G1; split into WW-00a and WW-00b. (ii) Gate (b) has no data at the operating h/c (IFW 0.36 only; Zhou pending; Pegrum not obtained): gate (b) becomes NOT_EVALUABLE and the claim ceiling is model-internal. (iii) "到達できた h/c の範囲に設計点を置く" brings back S1's risk; register an overlap rule: fraction of the operating envelope the solver can reach, weighted by time at each condition from team data; below a threshold WW-01 makes no performance claim. Confidence high.

**R-S8 (P2). §3.6: an RMS map from short URANS will under-flag.** T2-0d found SA URANS settles to a steady state; STATE says this is a statement about the 2D SA model. URANS would give near-zero RMS exactly in the regions that cannot be trusted. Fix: build the map from DDES (or SAS), or the union with the literature map; register the threshold; report sensitivity. Confidence medium-high.

**R-S9 (P2). §6.4, §6.6, §3.10: "same sign" checks have no noise criterion.** "別ビルドで同符号, 別コードで同符号" matches by chance half the time. The transition model checks only the drag constraint, not the gain. §3.10 says the DDES sign is not part of the pass while §6.6 says it is. Fix: require a lower confidence bound above 0 using the noise floor measured in that code; require the sign of the gain with a CI in the transition model too; reconcile the DDES rule with a sampling-error CI and a DDES-grade mesh. Confidence high.

**R-S10 (P2). §6.4, §3.5: the claim factor k is ambiguous and P(PASS) is not stated.** "利得 ≥ k σ_claim" appears to reuse k = 8; with remeshing noise of 0.2-0.9 % of Cl the threshold could reach ~6 % of rear-wing downforce; PASS requires ~nine conditions at once. Fix: define k_claim from the confidence level; state the expected P(PASS) before funding (as XV-01 does); say which failures end the trajectory at the last good iterate and which mean FAIL. Confidence medium.

**R-S11 (P2). §6.7: VAL-X statistics.** 15.7 = 2(1.96+0.84)^2 is for two independent samples; if sigma_rep is the SD of an out-and-back pair difference the factor is 7.85; define sigma_rep. The ranking-plus-magnitude rule needs its own power calculation by simulation. A "neutral" decoy leaves the ranking undefined: use a decoy predicted negative with |delta| >= delta, or a TOST equivalence test. delta is computed from whole-car ClA, but the first article is a wing measured on its mounts (~1/3 of the load, so n rises ~9x); test at the highest safe steady speed (n proportional to v^-4). Register the as-designed prediction as primary; CFD on the 3D scan is explanatory. Not done from S3: "budget the experiment now" and the V&V-20 comparison of E against u_val. Confidence high.

**R-S12 (P2). §11 is missing items.** The suspension arms (user listed them, §0 promises, §3.6 drops them). Team commitments: the aero lead's hand design (blind, hash registered before the optimisation starts); ride-height and attitude logs for WW-00; the lap-time simulation. The FD control arm should be part of decision (b), not "上限が許すときだけ". The pessimistic total for the full scope (~160-195 kUSD: caps at the high bounds plus 20 % reserve) is not given in §5.2. Confidence high.

**R-S13 (P2). §6.0, §8: the whole vehicle is exercised only at CAR-01.** Fix: add an exploratory LOOP-CAR-00: coarse half car ~5e6 cells, CAD ingest of every part, porous zones, rotating wheels, primal and adjoint, the sensitivity shares of S9; tens to hundreds of USD; catches whole-vehicle pipeline defects about a year earlier. Confidence medium-high.

**R-S14 (P2). §6.6, §9: the cooling constraint is missing.** Without a radiator mass-flow constraint the sidepod optimum closes the inlet. Fix: radiator mass-flow >= parent through the porous-zone pressure drop. Confidence high.

**R-S15 (P2). §3.9: M4 is tied to XV-01.** Every GEN-01 stage after M4 waits for XV-01's written-once analysis, yet GEN-01 consumes nothing from XV-01; XV-01 is not yet frozen and P(PASS) ~0.17. The consumer of RE-01 Stage 0 and R1 is the methodology paper. Fix: pre-declare that recording option C does not depend on XV-01's label, or say what label would change it; add the schedule risk to §9; name the paper as the consumer of RE-01; decision (c) is urgent because RE-01 Stage 0 is scheduled for week 1. Confidence medium-high.

**R-S16 (P3). Smaller items.** §1.1 "前翼規模" is the rear-wing stage. adoption.md S8 gives 8-19 kUSD while gen_cost gives 3.2-7.8 k and §5.2 4-8 k: reconcile. Constrain slot gap and overlap between elements using the phi of the frozen flaps (r_c 10-20 mm exceeds gaps of 5-15 mm). §9's ESI fallback must still pass §3.4. "目的の再定義" only through a new registration. TOPO-G's entry criterion measures pipeline maturity, not whether topology is needed. WW-00 and EVAL-3D-01 are not in gen_cost; WW-01's high bound (22 k) exceeds the WW-00+WW-01 cap of 15 k. The GEOM-K1 round-trip test uses sigma_claim before any study has measured it. Allaire's thickness constraint uses the design's own distance function, which moves; compute it exactly from the surface and test its gradient near the trailing edge and medial axis.
