# W-N review: GEN-01 rev 3 (0888d09f, SHA-256 effe84ff...b6f9209a verified): numerical, physical, statistical

(Opus reviewer, 2026-11-01, verbatim.)

**Verdict: GO_AFTER_FIXES.** The architecture fits the user's premise, and the per-run cost arithmetic reproduces. Four things are not yet defensible: the 3h thickness and 2.5h gap rules, the topology rules, a budget that ignores the plan's own noise, and the TR-01 label logic. Each can be fixed with cheap pilots before any registration.

## Findings

**W-N1 (P1; §0, §1.3, §3.1-3.2, §6.1). The "3h" minimum thickness has no basis in the cited records and is below what BDIM needs for thin bodies.** R0 is 1.5h on the design lattice and is "explicitly not a manufacturing or physical minimum"; WIDTH-RULE's R3 uses r = 0.75h; neither gives 3h. Lauber, Weymouth & Limbert 2022 (classic BDIM, eps = 2 dx) derive a zero-mu_0 core requirement of (4 + sqrt N) dx = 2 eps + sqrt N dx; disk test: d = 2 dx gives 4.4 % peak-force error, 4 dx gives 1.6 %; a wing about 2.7 dx thick leaks fluid and under-predicts lift and drag. The local WaterLily 1.8.0 source uses eps = 1 and sets mu_0 = 0 only for d < -eps; the same construction then needs about (2 + sqrt 3) h ~ 3.7h in 3D; at 3h a core exists only where the surface is grid-aligned; cambered elements at incidence will leak locally. The current harness samples phi through a trilinear lattice (GridSDFBody): across the medial ridge of a 3h slab the interpolated depth falls from -1.5h to about -h depending on phase. These errors (about 1.6-4 %) are the same size as the 2-4 % decision scale and change with t/h and orientation, so differences in t, alpha or camber are biased. Fix: in GEOM-S1/STAGE-0 run a Lauber-style ladder: hold physical t fixed and use h = 5 / 3.3 / 2.5 mm (t/h = 3 / 4.5 / 6) with at least 8 phases including z; measure C_L, C_D and one camber or alpha step difference; evaluate the analytic SDF at the faces (AutoBody), not a 5 mm lattice; set t_min where difference retention against the finest grid lies in [0.8, 1.25] and the phase SD is below sigma_target. Confidence high on the citations, medium on the 3.7h transfer to eps = 1.

**W-N2 (P1; §3.1, §6.2). The topology rules contradict the gates, and the union is not gated.** Vanish at t < 3h can never fire because t >= 3h is a constraint. Merge cannot be reached continuously because the gap >= 2.5h constraint makes the separated and merged states disconnected. MMC's continuous vanish depends on a sub-resolution density, which §1.3 forbids, so every event is discrete. Per-element analytic checks cannot see what the union creates: notches at overlaps, fluid slivers, enclosed cavities, element-endplate junctions. In a 2.5h slot the fully fluid (mu_0 = 1) band is only 0.5h wide; slot Re at Re_c 3e3 is about 125, so the slot is a viscous channel resolved by 2.5 cells and its flux is controlled by the kernel. Fix: restate vanish as "an element at the t bound for 2 checkpoints becomes a knock-out candidate", and make merge an explicit proposal tested like a seed; gate the scene with the R3 opening defect on both solid and void, plus connectivity and cavity gates; set g_min from a 2D BDIM slot test (flux error and phase spread for g/h in {2, 2.5, 3, 4, 6}).

**W-N3 (P1; §0, §3.3, §6.2, §6.4). At Re_c 3e3 the element-count physics is not FSAE's, so the user's core reason for the SDF may not survive transfer.** Trailing-edge boundary-layer thickness ~ 5c/sqrt(Re) ~ 0.09c ~ 27 mm, larger than the 12.5 mm minimum slot. Seeded elements (chord 0.3-0.6c) run at Re 900-1,800 as blunt stadium sections with t/c of 8-28 %. Slot and fresh-boundary-layer benefits (Smith 1975; van Dam 2002) need boundary layers thin relative to the gap. The event rules favour fewer elements. Expected outcome: 1-2 elements, the least informative answer for FSAE. Fix: before registering MW-01, run a TOPO-TRANSFER pilot: a 1/2/3-element series (the Zhang & Zerihan 2003 double-element geometry, thickened to be 3h-compatible), in WaterLily at Re_c 3e3 and in RANS at about 4.5e5 validated against their measured single- vs double-element delta C_L; if the sign of delta(1 -> 2 elements) differs between the two, record before spending that topology freedom is moot for FSAE; add an OC simulation of the final element-count distribution under the registered rules.

**W-N4 (P1; §1.3 row 3, §3.2, §6.2). Element positions are rigid translations, and FID-01 showed that rigid heave does not transfer.** FID-01: heave -31.1 has rho = 0.08 [0.02, 0.36]; heave +31.1 reverses sign; in WaterLily the heave response is grid-sensitive (flow_48/flow_32 ratios 1.49 and 0.62) because z is never phased. In ground effect z (h/c and element gaps) is the key variable. JOB-02 cannot phase z within a kernel. If the ground is a domain wall, a sub-cell z-phase changes h/c by up to 0.017, worth several percent of downforce; ground velocity is unspecified; a stationary no-slip mesh-SDF ground would be wrong. Fix: phase all three axes (RE-01's new source adds a z-shift); model the ground as a moving BDIM half-space (V = U) that shifts with the scene; before MW-01 frees them, run a registered FID-type check of rigid x and z element translations at the same Re.

**W-N5 (P1; §3.4-3.5, §5.2, BUDGETS). The budget assumes one evaluation per FD point or CMA sample, despite the plan's own noise statement.** RE-01's analysis: in chaotic flow sigma_d = sqrt 2 SE_T with the window chosen so that SE_T is about 1.5 %; at Re 80 SCREEN-01 had about 0.2 % per pair. Central FD meeting Carter's xi_g <= 0.5 needs an RMS SNR of at least 2, so r = ceil(8 sigma_F^2 / Delta^2) replicate phases per point: sigma_F 1.5 %, Delta 2 % -> r = 5 -> 4,500 evaluations (33 days on one 5090); Delta 1 % -> r = 18 -> 16,200 (118 days); the plan's 945 holds only if STAGE-0 finds a steady regime (sigma about 0.2 %). The roadmap's Moré-Wild analysis already found no usable one-sided FD window at Re 80; here the noise is ~7x larger. Fix: register the budget as a formula of STAGE-0's sigma_F and Delta, branch explicitly on steady vs unsteady, prefer a steady-regime parent (the ATT-00 aim), recompute before buying the GPU.

**W-N6 (P1; §3.4). The inherited k = 8 is infeasible.** Rev 2 derived 8 sigma_step = 0.37-0.54 % from sigma ~ 0.047 % (attached 2D RANS). With sigma_d ~ 2.1 %, 8 sigma_d is about 17 % per accepted step; SCREEN-01's total gain was 4 %; the run would be NOISE_LIMITED at iteration 0; even 16 replicates leave 4.2 %. Carter's (14) needs xi_g, which rev 3 never estimates for FD. Fix: re-derive the constants on the replicated step difference; Sun-Nocedal relaxed ratio test or STORM-style sample-size control (Chen, Menickelly & Scheinberg 2018); restore the feasibility check expected gain / (k sigma) >= 3.

**W-N7 (P1; §3.4-3.5). CMA-ES as specified, and its acceptance rule.** lambda = 12 is below the default 4 + floor(3 ln n) = 15 for n = 40. The covariance-learning horizon (~n^2/mu_eff) is about 230-290 generations (~3,500 evaluations); 60 generations is a step-size-adapted near-isotropic ES. Hansen's tutorial: step-size adaptation fails on very noisy functions. "Judge each generation's best against the floor": the expected maximum of 12 standard normals is 1.63; with sigma_F = 1.5 % noise alone inflates the best by about 2.4 %, so it passes the floor by construction. Roadmap §4.4 already concluded that model-based derivative-free methods beat CMA-ES at small budgets. Fix: claims only on fresh-phase re-evaluation of the CMA mean, or of the top k with two-stage selection; put sequential SCREEN-type response surfaces in the OC as a primary candidate (they average noise across all points); include Py-BOBYQA/DFO-LS and UH-CMA-ES; price restarts after dimension-changing topology events.

**W-N8 (P1; §3.4 topology events; §5.2 row 4). Event statistics and cost.** Power is adequate: with sigma_d 2.1 % and the 1.44 upper-bound factor, 16 pairs give power 0.92 at a 2 % effect and 0.31 at 1 %. Knock-out decides on absence of evidence: register it as a parsimony rule or a TOST non-inferiority margin. About 10 tests per checkpoint at alpha = 0.05 each need Holm correction. Single-evaluation seed screening cannot rank seeds whose effects differ by 2-4 % (expected best-of-5 inflation 1.18 sigma). Cost: each test needs 16 parent + 16 candidate runs; per checkpoint 16 + 5x16 knock-outs + 5x16 seeds ~ 176; ten checkpoints ~ 1,760 evaluations (12.8 days on the 5090), against 126 in the model. Fix: group-sequential tests, a shared parent phase set at each checkpoint, about 3 checkpoints, then re-cost.

**W-N9 (P2; §0, §1.2, §3.3). "Re_c 1e3-8e3 is the iLES validation range" is an overclaim.** Weymouth & Font 2025 validate the Taylor-Green vortex at Re 1600, a sphere at Re 3700 with 88-168 cells per diameter (C_D within 4 % of DNS on the large domain), an oscillating cylinder at Re 7620 with about 21 cells per diameter. RE-01 says "defensible to Re_c ~4e3 with sphere-class resolution", descriptive at Re_L 8000. The main line has 60 cells per chord and a leading-edge radius of 1.5 cells, smaller than the 2-cell BDIM band, so leading-edge separation is kernel-controlled; the repository has never run above Re 250. The "confirmation" at h 2.5 mm and Re_c 1e4 conflates grid and Re. Fix: make STAGE-0 a gate with RE-01's RESOLUTION_LIMITED ([0.5, 2] on b_3.3/b_5), DOMAIN_SENSITIVE and NUM_SENSITIVE controls, applied to the parent, one element shift and one element addition; confirm at a fixed Re_c 3e3; treat Re 1e4 runs as descriptive.

**W-N10 (P2; gen_cost_wl.py, §3.2, §5). Cost-model check.** Hand recomputation reproduces (front wing h 5 mm: 7.2e6 cells, 24,000 steps, 0.87 h T4, 0.17 h 5090; h 2.5 mm: 5.76e7, 62,400, 18.2 h, 3.6 h). The throughput anchor matches UNC-01 (f32 Julia wall median 340.6 s, f48 2,267 s); about 68 s of process overhead is excluded (~11 % at 0.17 h). The anchors were measured at Re 80 (viscous time-step limit, Candidate C Poisson settings); GRID-02 implies a fixed ~5 ms/step overhead, so 4.5-5x for the 5090 is the estimate; it needs measuring. Errors: h 3.3 mm costs x5.1, not x3 (h^-4: 2.43e7 cells, 36,000 steps, 4.4 h T4, 0.88 h 5090), missing from the table; the h 3.3 verification (~28 GPU-h) is priced at h 5 cost; the window is fixed at 150 c/U while RE-01's S0 formula can require up to ~520 c/U; CFL 0.5 may be optimistic in slot and under-wing jets (25-50 % more steps). The domain (5c x 3.3c x 2c) has a high top-boundary blockage that changes with element count, with no domain control. The v18 parent option (c = 1.22 m) costs x256 unless rescaled. CTX-01 at h 25 mm cannot represent a 15 mm element (0.6 cells).

**W-N11 (P1; §2 F(2), §6.2, §5.3). The same-Re OpenFOAM tier has no cost and little power.** §5.3 prices only steady RANS. RE-01 anchor: laminar pimpleFoam at Re_L 800 on V2 (213k cells) ~21 CPU-h per case; a 3D multi-element case at Re_c 3e3 is likely 300-1,000 CPU-h per case; eight cases are 25-80 days on the 4-CPU Docker Mac. With 4 pairs (t at df 3 is 2.353) the mean must exceed 1.18 s_pair; "pair" is undefined for a body-fitted mesh. Fix: price it, define pairs (XV-01-style shifts), use spanwise-periodic sections, or keep it descriptive as RE-01 did.

**W-N12 (P1; §6.4). The TR-01 label logic is not sound as written.** It is not "the same form as RE-01": RE-01 regresses 8 designs (df 7); TR-01 has one ratio of two noisy differences, which needs a Fieller interval; model-form spread (SA vs SST vs gamma-Re_theta) is not covered by a t-interval over 8 mesh realisations. RE-01 rejected exactly this design (one 3D RANS pair at Re 5e5: model spread >= 33 %, no reference, pipeline unqualified); T2-0b/c/d all ended NO_GO. Blunt 15 mm trailing edges shed strongly (Re_t ~ 1e4 at Re 2e5); steady RANS ends in a limit cycle, so the likely label is NUMERICAL. At flap Re ~6e4 transition is set by the trip and the model. PERSISTS can come trivially from blockage or base drag shared across Re. Run count: 3 models x 2 Re x 2 families x 8 realisations x 4 designs = 384 runs, against "2-3 weeks on the Mac" (~64 runs). Fix: worst case over (model, family), INDETERMINATE when models disagree in sign; Fieller interval with the fresh-phase denominator; cost a URANS fallback; qualify the RANS pipeline on Zhang & Zerihan's double-element data first; add TR-01b (the same layout rendered with real sharp-trailing-edge sections, labelled separately); add high-Re hand-design and random controls.

**W-N13 (P2; §3.6). The RPM gradient track.** Campobasso & Giles 2004 (read) apply RPM to a preconditioned fixed-point linear iteration whose base flow ends in a low-level limit cycle; Skamagkis et al. 2021 apply RPM plus ATC damping to a steady adjoint about averaged fields; both solve steady or pseudo-time linear problems. For WaterLily, RPM is plausible at Re_L 80/250: solve (I - dF/du) u_dot = dF/dp for the one-step map F using ForwardDiff Jacobian-vector products. DIAG5's +-1 ulp sensitivity points to non-smooth kernels (flux limiter, mu_0 threshold, sign-consistency branch in measure!); RPM cannot fix non-differentiability, so the smooth scheme must come first. The "steady thin plate at Re_c 3e3" gate case likely does not exist (blunt TE, Re_t ~ 150). The main line is unsteady: RPM would give a mean-flow sensitivity with unknown xi_g; chaotic flow needs shadowing methods. "Replaces FD, about 10x fewer evaluations" is unsupported; a Carter check in the unsteady regime costs 16 directions x 2 x r (r = 5-18), i.e. 160-580 evaluations. Fix: limit the success claim to the steady regime; add an unsteady gate before any replacement.

**W-N14 (P3).** Estimator A is a per-pair SD and B is a per-run SE; compare A with sqrt(B_c^2 + B_b^2). "Retention >= 0.5 at h 3.3" needs an interval and an upper bound, as in RE-01's [0.5, 2]. The noisy drag <= parent constraint needs a one-sided margin. "R3" (grid confirmation) collides with WIDTH-RULE R3. Using an upper bound of sigma_d from STAGE-0 as a test input needs a written PROC-01 engineering-parameter formula.

## What the plan gets right
- Returns to the user's premise: GPU, fixed grid, low memory, SDF straight onto the grid.
- The claim ceiling is honest: no FSAE claim from WaterLily; transfer is gated.
- Each element is an exact analytic SDF with no re-initialisation; boundaries stay sharp and Brinkman is excluded.
- Keeps paired same-phase differences, a fresh-phase final claim, blind hand-design and random controls, and records events separately from labels.
- AD stays off the critical path (R5), and RE-01/ATT-00 are central.
