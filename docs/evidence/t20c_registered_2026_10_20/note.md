対象は Tyrrell 026 単一翼の 2D 断面です。Re_c 4.6×10⁵、移動地面で、OpenFOAM v2512 の SA 壁関数を Kaggle CPU で実行しました。モーフィング（トポロジーを固定し、節点を写像する方法）と再メッシュを、med30、fine30、xfine30（新しい段）で比べています。判定は fine30 と xfine30 で行いました。
閾値は T2-0a と T2-0b を見た後に決めたものです。判定には新しい run だけを使いました。qualification flag は変更せず、shape_update_allowed は false のままです。

## 分かったこと（判定は変えない）
- **定常性**: 定常の読み方ができないケースが 26 件ありました。
  - xfine30 では、h/c 0.09 の全迎角で plateau に達しません（継続計算の後も、Cl の生の揺れは 2.7–5.4 %）。h/c 0.134 では、迎角 0° 以上が UNSTEADY（0.7–2.0 %）です。負の迎角では定常になります。
  - fine30 では、h/c 0.09 の +1° だけが揺れます（1.9 %、T2-0b と同じ）。T2-0b の G3b が不合格だった根拠は、このケースでした。
  - メッシュを細かくすると、剥離する高さとピークの高さで定常解が得られなくなる、ということです。
- **雑音**: モーフで、迎角を変えたときの跳びは大きく減りました。σ_R と σ_M の比は、幾何平均で 8.2 倍です。fine30 の h/c 0.224 では、分解できる最小の迎角変化が 0.24° から 0.009° になりました。再メッシュのままメッシュを細かくしても、T2-0b の G6 と G3b の不合格は直りません。fine30 の再メッシュの σ は、med30 より大きくなっています。
- **med30（T2-0b の主メッシュ）**: 同じ規則のラベルで見ると、T2-0b で落ちた h/c 0.134 の ±0.25° は、モーフでは合格します。モーフと再メッシュの微分も、3 高さで一致します。
  - ただし h/c 0.134 では、ベースメッシュの実現によって微分が 0.047 と 0.066 に分かれます。fine30 でも 0.063 と 0.086 です。どちらも大きいほうの値の 26–29 % にあたります。
  - つまりモーフは跳びを消しますが、ピーク付近ではベースメッシュの雑音が微分に凍結されて残ります。h/c 0.224 では、ベースを替えても差は 0.5–4 % です。
- **メッシュ系列**: 計算できたのは h/c 0.224 だけです。Cl は med30 1.345、fine30 1.308、xfine30 1.271 で、同じ幅ずつ下がりました（DIVERGENT）。Cl の最大の位置（PEAK）と、fine30・xfine30 での G2 の再判定は、入力が UNSTEADY または SOLVER_FAIL のため計算できません。
  - このため、この研究から G2 の経路は決まりません。T2-0b の G2 の行動（壁面解像／LM の評価器の研究か、別の検証ケース）が、そのまま既定になります。
  - 記述として: xfine30 では高い車高ほど実験値に近づきます（h/c 0.671 で 0.921、実験は 0.903）。
- **形状（記述のみ）**: ラベルは `SHAPE_NOT_RESOLVED` です。
  - h/c 0.224 と 0.134 のキャンバーとフラップは、分解でき、線形で、med30 と fine30 の間でも、再メッシュとも一致します。
  - heave（車高 ±0.25／0.5 mm）は、h/c 0.134 と 0.09 で分解できません。
- **再現性**: 判定は変えません。
  - T2-0b とは、41 形状のうち 36 でメッシュの SHA-256 が一致しました。Cl の最大差は 3.0e-6 です。gmsh は、実行ごとに番号付けの違うメッシュを出します。
  - kernel M は AMD EPYC、R と S は Intel Xeon で動きました。
