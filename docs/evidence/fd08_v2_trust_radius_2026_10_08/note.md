# FD-08 v2 R6 モデルの trust radius（solver 不要・事後・未登録）

証拠区分: `solver_free_post_hoc_extrapolation_of_frozen_micro_response_models_unregistered`。
R6 PASS 8/8 と formal PASS 24/24 は変更しない。6 つの qualification flag は false のまま。
再現: `.venv/bin/python scripts/analyze_fd08_v2_trust_radius.py`（`result.json` と SHA 一致）。

## 何を計算したか
R6 で固定した 8 系列の Model A（`S = g·ε + c·ε³`）と Model B（`S = g·ε + k·ε|ε|`）から、
高次項が線形項の 5/10/20% に達する ε（trust radius）を求めた。保存済みの beta・共分散だけを使い、
`fd08_v2_gate.evaluate_series` による再計算が 8 系列とも保存値と一致することを確認した（refit で結論は変えない）。
不確かさは、公称共分散（T2 の仮定ノイズ由来。測定ノイズではない）からの 20,000 回の parametric draw
（PCG64 seed 20261008）の 5 パーセンタイルで表す。ε は max=1 の phi 方向に掛ける **名目** 係数で、実効変位ではない。
SDF 格子 h=25 mm、flow 格子 33.3 mm。較正域は 0.5〜5 mm。

## 結果（高次項/線形項 = 10% の半径、mm）
| 系列 | Model A 点推定 | A の 5% 下側 | Model B 点推定 | B の 5% 下側 |
|---|---:|---:|---:|---:|
| D0 drag | 3.14 | 2.54 | 1.63 | 1.04 |
| D0 downforce | 6.84 | 4.19 | 7.77 | 3.13 |
| D1 drag | 5.48 | 3.47 | 4.03 | 1.75 |
| D1 downforce | 6.47 | 4.04 | 11.09 | 3.23 |
| D2 drag | 86.8（c≈0） | 4.59 | 466（k≈0） | 3.69 |
| D2 downforce | 5.87 | 3.63 | 5.21 | 2.07 |
| P1 drag | 10.2 | 4.53 | 19.7 | 3.70 |
| P1 downforce | 7.58 | 4.32 | 10.8 | 3.43 |

- 最も厳しいのは **D0 drag**（c の z=3.4。他は z≈0〜1.4 で、c が 0 と区別できない系列が多い）。
  10% 半径の 5% 下側は Model A で 2.5 mm、Model B で 1.0 mm。20% で A 3.6 mm、B 2.1 mm。
- 点推定が大きい系列（D2 drag など）は、c や k が 0 と無矛盾なためで、5% 下側は 3.6〜4.6 mm に収まる。
  点推定を「安全域」として使わない。
- formal の 24 点で、Model A の絶対誤差が Model B より小さい点は 13、大きい点は 11。決定的な差ではない
  （B は R6 の固定 fit を使った反実仮想。登録モデルは A）。

## 読み方と限界
- 較正域（≤5 mm、formal の内部は ≤3.97 mm）の内側では、補間検証の裏づけがある。
  それを超える半径は 2 つの仮定した関数形の外挿で、有効域の保証ではない。
- #47 STEP-01 の想定ステップ（0.1〜0.5 h = 2.5〜12.5 mm）のうち、上側（約 5 mm 超）は FD-08 の裏づけが無く、
  D0 drag は Model A の 10% 半径の下側（2.5 mm）が STEP-01 の下端に近い。**STEP-01 は、D0 drag では範囲全体で、他の系列でも上側のステップで要る**
  というのがこの解析の含意。実行するか・ステップ上限をいくつにするかはユーザー判断。
- 不確かさの注意: 共分散は公称（σ0=3 µN、ρ=0.05 はいずれも arbitrary-provisional）で、pilot の重みの不確かさは含まない。
  Model A と B の関数形の不確かさは「5% 下側」の外にある。換算カイ二乗は 0.00〜1.1 と小さく（D2・P1 の drag はほぼ 0）、
  c や k が 0 と区別できない系列の「5% 下側」（3.6〜4.6 mm）は、データではなく**仮定したノイズ**で決まっている。
  「5% 下側」は plug-in の parametric 5 パーセンタイルで、信頼限界でも安全域でもない。
- ε は max=1 の phi 方向に掛ける名目係数である。STEP-01 の 2.5〜12.5 mm（0.1〜0.5 h）を同じ意味の名目ステップと
  **仮定して**比較している（この対応は未検証）。この仮定のもとで、D0 drag の Model B は 10% 半径の点推定（1.63 mm）も
  「5% 下側」（1.04 mm）も STEP-01 の範囲全体（2.5 mm 以上）より小さい。Model A でも 5% 下側（2.5 mm）は下端に並ぶ。
- ここから gradient 精度・物理的正しさ・格子独立性・ε→0 の厳密な微分は主張しない。
