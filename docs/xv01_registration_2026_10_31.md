## 1. Question, hypothesis and claim ceiling
**Question (L2, roadmap M3b-2; #65).** Does the WaterLily-selected SCREEN-01 finalist keep, in independent body-fitted CFD on three OpenFOAM meshes never used for selection, a paired downforce gain over the v18 parent of at least the FID-mapped OpenFOAM minimum on every mesh, with drag confirmed not increased on every mesh, with the FID fidelity rules (sign, retention, V1-V2 spread, V3 consistency) satisfied and with the OpenFOAM difference insensitive to the STL export resolution (r = 4 vs r = 8)?

**Hypothesis.** The SCREEN gain is not an artefact of the WaterLily solver family, of its grids or of the selection among K_opt = 19 WaterLily candidates: it persists on OpenFOAM V1, V2 and V3 above `g_OF` with drag non-increase.

Claim ceiling: Re = 80 laminar steady OpenFOAM v2512 (local Docker, the U3/X3 pipeline, three snappy meshes, not grid-converged) for **one** WaterLily-selected finalist against **one** analytic parent (v18), uncertified geometry, the r = 8 STL (r = 4 as the export-resolution control), three-axis sub-cell STL shifts of 0.5-4 mm per axis from a fixed Halton panel (the bottom wall is fixed, so a shift also changes the ground distance by up to 4 mm), paired same-shift differences. An `XV01_PASS` is the L2 statement **for this finalist at Re 80**: its WaterLily improvement is confirmed by a solver and meshes independent of the selection, on the same SDF-derived STL geometry. It is not physical downforce, not grid independence or a GCI claim, not FSAE, not high Re, not a fidelity statement for the camber extension beyond the designs measured here, not a statement about the optimizer's general reliability (one draw), and it says nothing about the finalist's minimum feature width (R0 is re-run at the native placement, not re-measured on the continuous shape). The finalist lies in the camber extension (u = -1.5, -29.55 mm) where FID-01 has no fidelity evidence, and its WaterLily drag neutrality is a cancellation (+4.5e-3 N camber and pitch against -6.0e-3 N reflex) that relies on an OpenFOAM camber drag retention FID-01 did not judge (§7.3); both are what XV-01 measures, not assumptions it inherits, and both are mandatory fields of every outcome record (§8).

Outcomes (§5.9): `XV01_PASS`, `XV01_FAIL` (a resolved failure on the completed run set; cause list), `XV01_UNRESOLVED` (run set completed; a rule not resolved, a chain control not judged, a V3 value above the band, case-level data insufficient, or the finalist not runnable), `XV01_INCOMPLETE` (a registered formal kernel lost after its rerun or not run), `XV01_INVALID` (a judged chain control fails: NC, REF or determinism). Pre-run terminal records (§2.1): `XV01_NOT_REGISTERED(cause)`, `XV01_NOT_FUNDED`. Registered secondary labels (no effect on the outcome): `XV_OF_CORE`, `GAIN_RESOLVED_ABOVE_FLOOR_{V1,V2,V3}`, the drag resolution labels per level, `DRAG_MATERIALITY`, `XV_DRAG_MESH_DEPENDENT`, `G5B_NOT_TESTED`, `G5B_DESCRIPTIVE`, `OF_OPT_VS_MANUAL`, `OF_OPT_VS_RANDOM`, `EXT_V1_RETENTION`, `ENV_DRIFT_END`, the retentions and ratios of §5.10.

### 4.4 Budget
- **Cap 400 CPU h** of formal case wall (the summed stage wall of every formal case, kernel reruns included).
- **Freeze-2 limit:** the budget record bound by freeze 2 computes `T_0` for the whole formal run set without reruns, with the finalist's V3 case cost from the probe (`450 s + 7.27 s x probe iterations`, or the probe's measured wall if larger) and FID's measured costs otherwise; `T_0 <= 250 CPU h` is required (it leaves at least 150 CPU h, more than one rerun of a whole V3 wave even at endTime 12000), else `XV01_NOT_REGISTERED (BUDGET)`.
- **During the run:** before every rerun and before V3 wave 2, `T = sum(case wall of finished formal kernels) + sum(estimates of every unfinished formal kernel, reruns included)` is written once as a budget record; if `T > 400 CPU h` the pushes stop, the kernels never run are declared `--not-run KERNEL=BUDGET` citing the record, and the outcome is `XV01_INCOMPLETE (BUDGET)`. There is no override; a different cap needs a re-registration (§8.2).
- **Smokes, replays and the probe** are bounded separately: at most 40 CPU h, with the attempt limits of §4.6. No new spending: local CPU only.

### 4.5 Case validity, status map and matching
- **Valid case** (FID §5.4): every stage returns 0 (checkMesh exit 1 allowed only for the registered single concave-cell failure with fraction <= 0.08; the raw `Failed 1 mesh checks.` line is that allowed output, AGENTS.md), simpleFoam reports `SIMPLE solution converged` before endTime, and both window means are finite.
- **Status map** (the runner's case statuses): *physical results* (a result about the shape at that shift, never a rerun): `blockMesh_FAILED`, `surfaceFeatureExtract_FAILED`, `snappyHexMesh_FAILED`, `checkMesh_FAILED` (other than the allowed concave case), `simpleFoam_FAILED`, a completed case without convergence, a non-finite window mean. *Infrastructure* (a kernel loss: one identical full-kernel rerun, §10): `RUNNER_EXCEPTION`, `PARSE_FAILED`, any `NOT_RUN_*`, a stage timeout, `local_run.json` return code ≠ 0, `dpkg_after_matches_lock` false, an install-guard failure, a missing case record. The mapping is a freeze-1 signature table; every attempt gets a classification record.
- **Matching** per state and level: the mirror pairs where the state and the parent are valid at both members (whole-pair unit). A failed parent case removes that pair for every state of that level.
- **Minimum data** (pairs valid for the state and the parent): finalist V1 >= 12, V2 >= 3, V3 >= 3; EX >= 12 (§5.7); NC and REF >= 12. Below a minimum the rule that needs it is `UNRESOLVED_DATA`.
- **`FINALIST_ASYMMETRIC_LOSS`**: a finalist case (r = 8 or r = 4) invalid at a shift where the parent's case of the same level and STL resolution is valid; on any level it keeps the outcome out of PASS (§5.9 step 6), reported per shift.

### 4.7 Blinding
While the smokes, the probe and the formal kernels run, only statuses, stage return codes, cell counts, iteration counts and times are read, through a hashed status extractor with a key whitelist (`id`, `state`, `status`, stage names and return codes, `timed_out`, `mesh.cells`, `mesh.only_allowed_concave_failure`, `solver.converged_in`, `solver.iterations`, `total_wall_s`). The sanitiser (hashed in freeze 1) removes `forces`, `coefficient.dat` and the solver logs' force lines from every smoke and probe output and asserts that none remains; only the replay kernels keep forces. Forces of formal cases are read only by `analyze_xv01.py main`, after every formal kernel is valid or declared lost or not run. No value of any XV case changes a rule, a state, a shift, a mesh or the run set; the OpenFOAM meshes are judgment-only holdout data, never fed back into geometry, mesh or candidate selection.

## 5. Rules (computed by the frozen `scripts/xv01/analyze_xv01.py`, cross-checked by the independent checker)
Responses: downforce (objective) and drag (constraint), N, the window means of the runner. Differences are state minus parent at the same shift on the same level and STL resolution; the sign of the finalist's WaterLily difference is s = +1.

### 5.1 Estimators and the single-finalist uncertainty (requirements §2.1)
- **Unit.** For state x, level L and mirror pair j: `d_Lj = ((F_x,L,j+ - F_parent,L,j+) + (F_x,L,j- - F_parent,L,j-)) / 2`. The two mirror members are never counted as independent samples.
- **Level estimate.** `Delta_L = mean_j d_Lj` over the matched pairs J_L (n_L = |J_L|); `s_L` = the sample SD of the units (n_L - 1 dof).
- **Standard error.** `SE_V1 = s_V1 / sqrt(n_V1)` (FID §6.1, unchanged; dof 15 at 16 pairs). `SE_V2 = max(s_V2, f) / sqrt(n_V2)` and `SE_V3 = max(s_V3, f) / sqrt(n_V3)` with the floor `f` = the FID V2 pooled pair SD of the response (downforce `1.984576864434452e-4 N`, drag `1.3747177622390572e-4 N`; an OpenFOAM-internal within-design placement SD pooled over 12 designs, dof 12). `t_L = t_{0.95, n_L - 1}` (one-sided; 1.753 at 16 pairs, 2.353 at 4 pairs).
- **Why this rule.** FID's V2 SE pooled the pair variance of 12 designs and its V3 SE was the leave-one-out residual of the tier-A V3-on-V1 regression; neither exists for one finalist and neither is copied (the 1.45e-3 N residual is driven by one design — 5.3e-4 N without camber -19.7 — and mixes placement noise with design-to-design grid departure; it is not a measurement SE). Each level carries its own ensemble of 4 mirror pairs (option A′ of the preparation note: dof 3 on V2 and V3), and the floor prevents a spuriously small SE from a near-zero sample SD of a deterministic solver; SE = 0 is never inferred. FID's V2 single-shift SD (4.2e-4 N) makes the floor a plausible V3 scale, neither clearly conservative nor anti-conservative (numerical review). The WaterLily `sigma_d` is never used on the OpenFOAM side.
- **Sampling meaning (stated, not assumed away).** The shifts are a fixed deterministic Halton panel of the X3 generator (per-axis magnitudes 0.5-4 mm, signs from separate Halton bases, exact mirror pairs), not an iid sample. `SE_L` is the empirical spread of the paired units over this panel, used as a placement-sensitivity scale with conventional t quantiles; no frequentist coverage is claimed. The four pairs 81-84 shared by V2 and V3 are sign-imbalanced (their "+" members are z-positive; mean sign(xz) = sign(yz) = -0.5), and the V1 mean over these four pairs differs from the 16-pair mean by about 4e-4 N (planning SD). Because the bottom wall is fixed, the spread includes the ground-distance change of up to 4 mm; it is not pure mesh noise and not a physical attitude invariance. The force-window SD of a single case is an iterative-convergence diagnostic and is never used as a placement SE.

### 5.2 Gain floor (FID §8 mapping; requirements §2.4)
**`x_OF = 3.3687409403100554e-3 N`** (frozen) `= g_OF J_b,48` with `g_OF = 0.012674959854238867` and `J_b,48 = 0.26577921974115387 N`, the same level on V1, V2 and V3. FID §8 states `g_OF` without the normaliser of an OpenFOAM difference; its active term `S_d,OF` is normalised by the OpenFOAM parent (V3). XV takes `J_b,48`, the SCREEN normaliser and the basis of the SCREEN §5.7 projection (which compares `% of J_b,48` with 1.27 %); it is the stricter reading by 1.25-1.32x (the OpenFOAM-parent reading gives 2.56-2.69e-3 N, reported beside it as `Delta_L / |F_bar_parent,L|`). No other floor, no 0.68 %, no 2 %, no literal-E2 term is added.
- **GAIN_L** (L = V1, V2, V3): `PASS` if `Delta_L >= x_OF` and `Delta_L > 3 SE_L` (the FID tier form, as SCREEN G); `FAIL` if `Delta_L + t_L SE_L < x_OF` (bounded below the floor); else `UNRESOLVED_STAT`; missing `UNRESOLVED_DATA`. Label `GAIN_RESOLVED_ABOVE_FLOOR_L` = `Delta_L - t_L SE_L >= x_OF`.

### 5.3 Drag non-increase (the SCREEN constraint, allowance 0; requirements §3b)
- **DRAG_L** (every level): with the drag unit estimate `D_L` and `SE_L`: `PASS` iff `D_L + t_L SE_L <= 0`; `FAIL` iff `D_L - t_L SE_L > 0`; else `UNRESOLVED_STAT` (labels `PASS_UNRESOLVED` for `D_L <= 0`, `VIOLATION_UNRESOLVED` for `D_L > 0`); missing `UNRESOLVED_DATA`. Every level must pass.
- **Meaning and power (stated).** PASS is a **confirmed** non-increase: the one-sided 95 % upper bound of the drag change must be at most 0, so a design whose true drag change is 0 cannot pass and one at -1e-4 N almost never does. With the floor binding on V2/V3 the effective thresholds are `PASS iff D <= -1.62e-4 N`, `FAIL iff D > +1.62e-4 N` (0.05 % of the 0.33 N parent drag). Power for a common true drag change D on all three levels (numerical review; V1 pair SD 5e-4 N, V2/V3 SD at the floor): D = 0 → P(PASS) 0.00, P(resolved FAIL) 0.06; -1e-4 → 0.00 / 0.01; -2e-4 → 0.17 / 0; -3e-4 → 0.64 / 0; -4e-4 → 0.91 / 0; -6e-4 → 1.00 / 0 (with a V1 pair SD of 8e-4 N, P(PASS) at -4e-4 N is 0.60). No allowance is added: the requirements re-evaluate the registered constraint (memo D4).
- **Labels.** `DRAG_MATERIALITY` = every level's upper bound `D_L + t_L SE_L <= 5.397769910001766e-4 N` (the finalist's SCREEN drag SE_eff: the resolution at which L1 decided the constraint); it changes no outcome and is read by §8.1. `XV_DRAG_MESH_DEPENDENT` iff the three point signs are not all of one side of zero. The drag price `D_L / Delta_L` is reported. The SCREEN drag decision (point sign, `PASS_RESOLVED` there) is not inherited; the WaterLily interval [-3.26e-3, -0.72e-3] N is reported beside the OpenFOAM values.

### 5.4 Fidelity rules inherited from FID §6.3 (applied to the finalist as a tier-A design)
- **G1 sign on every level**: `PASS` if `Delta_L > 0`; `FAIL` if `Delta_L < 0` and `|Delta_L| > 2 SE_L`; else `UNRESOLVED_STAT`; missing `UNRESOLVED_DATA`. (Implied by GAIN; computed for the cause attribution.)
- **G2 above 3 sigma on V1**: `PASS` if `Delta_V1 > 3 SE_V1`, else `UNRESOLVED_STAT`. (Implied by GAIN_V1.)
- **G3 spread V1-V2** (FID literal): `m = (Delta_V1 + Delta_V2) / 2`, `R = |Delta_V1 - Delta_V2|`, `sigma_R = sqrt(SE_V1^2 + SE_V2^2)`: `PASS` if `R <= 0.5 |m|`; `FAIL` if `R - 2 sigma_R > 0.5 |m|`; else `UNRESOLVED_STAT`; `m <= 0` → `UNRESOLVED_STAT`. `sigma_R` assumes no V1-V2 covariance although V2 shares 4 of the 16 V1 pairs; FID's V1 and V2 pair deviations were uncorrelated across 12 designs (r = 0.03 downforce, 0.23 drag), and a positive covariance would make the FAIL side conservative. The common-pair version (`R_J`, `sigma_R` from the per-pair differences) is reported.
- **G4 retention on V1**: `rho = Delta_V1 / Delta_32` with the SCREEN confirmation `Delta_32 = 1.0774190511977672e-2 N`, `SE_eff = 2.9231082773713274e-4 N`, `t = t_{0.95, min(P, n_V1) - 1}` = 2.353 (P = 4; FID's choice, larger than the 1.753 of GAIN/DRAG on the same `SE_V1`): `FAIL` if `Delta_V1 + t SE_V1 < 0.5 (Delta_32 - t SE_eff)` (5.043e-3 N minus `t SE_V1`) or `Delta_V1 - t SE_V1 > 2 (Delta_32 + t SE_eff)`; `PASS` if `0.5 <= rho <= 2.0` (`Delta_V1 >= 5.387e-3 N`); else `UNRESOLVED_STAT`. **G4, not the floor, is the binding V1 requirement**: 5.387e-3 N is 1.6x `x_OF`, and `Delta_32` is the selected design's WaterLily value, so the expected selection attenuation sits in the denominator (§7.1). The upper arm (it needs `Delta_V1 > 2.29e-2 N`) is inherited and immaterial here. `rho_V2`, `rho_V3` reported.
- **G5 constraints**: (a) geometry — established at P0 (§3.2; PASS before any case, else §2.1); (b) drag fidelity — eligible only where `|Delta_drag,32| >= 2e-3 N` and `> 3 SE_eff`; the finalist's `|-1.99387e-3| N` is below 2e-3 N by 6.1e-6 N, so G5b is `PASS` with the note "not tested" (label `G5B_NOT_TESTED`), which carries no constraint information: compliance is decided by §5.3 only (requirements §3.1). Descriptive `G5B_DESCRIPTIVE`: `rho_drag,V1 = D_V1 / Delta_drag,32` with the FID band label it would have had, and the eligibility it would have had on the flow_48 drag (-2.795e-3 N).

### 5.5 V3 consistency for one finalist (adaptation of the FID G3-set; requirements §2.2)
FID's G3-set judged the slope of `Delta_V3` on `Delta_V1` through the origin across 8 tier-A designs against [0.6, 1/0.6]. For one finalist it is judged on the common pairs `J = J_V1 ∩ J_V3 ⊆ {81, …, 84}` (|J| >= 3 and `mean_J d_V1 > 0`, else `UNRESOLVED_DATA`) with the margin units `lo_j = d_V3,j - 0.6 d_V1,j` and `hi_j = d_V1,j / 0.6 - d_V3,j` and `SE(·) = max(sd(·), f_DF) / sqrt(|J|)`, `t = t_{0.95, |J| - 1}`:
- **lower side**: `PASS_LOW` if `mean(lo) >= 0`; `FAIL` (`OF_MESH`) if `mean(lo) + t SE(lo) < 0` (V3 resolved below 0.6 V1: boundedly negative); else `UNRESOLVED_STAT`;
- **upper side**: `PASS_HIGH` if `mean(hi) >= 0`; if `mean(hi) + t SE(hi) < 0` (V3 resolved above V1 / 0.6) the rule is `UNRESOLVED` with cause **`V3_ABOVE_BAND`** — the gain is larger on the finest mesh, which does not contradict the improvement and is not a constraint violation; the requirements note §4 names a V3 conflict as `XV01_UNRESOLVED`; else `UNRESOLVED_STAT`;
- the rule passes iff both sides pass (the point ratio of the common-pair means lies in [0.6, 1/0.6]; the FID point-pass form).
Never a silent drop of V3: a missing V3 is `UNRESOLVED_DATA` and blocks `XV01_PASS`. Operating characteristics (numerical review; 4 common pairs, dof 3, V1 pair SD 1e-3 N, V3 3e-4 N): true V3/V1 = 0.4 → P(point pass) 0, P(resolved departure) 0.93-0.99; 0.5 → 0.00-0.02 / 0.49-0.66; 0.6 → 0.50 / 0.05; 1.0-1.4 → >= 0.99 / 0; 1.52 (FID camber -19.7) → 0.89 / 0.004; 1.67 → 0.50 / 0.05; 1.8 → 0.12-0.14 / 0.21-0.24; 2.0 → 0.00 / 0.67-0.74; 2.2 → 0 / 0.94-0.97. The floor practically never binds (an SE = 0 guard). Reported: `Delta_V3,J / Delta_V1,J`, `Delta_V3 / Delta_V1` (16-pair V1), `Delta_V3 / Delta_V2`, and `|Delta_V3 - Delta_V2| / |F_bar_parent,V3|` (to compare with `S_d,OF`). This is a new single-design adaptation, stricter than the set rule (one design is judged alone; FID's camber -19.7 had a V3/V1 ratio of 1.52 inside a set slope of 1.086); it is not called the FID rule.

### 5.6 Chain controls
- **NC** (FID §6.6, OpenFOAM form): `z = |Delta_roll,V1 - (-6.614761397334482e-4)| / sqrt(SE_roll,V1^2 + (5.792182318004298e-5)^2)`; `CONSISTENT` if `z <= 3.5`, else `NOT_CONSISTENT` → `XV01_INVALID`; fewer than 12 valid roll pairs → `MISSING` (→ §5.9 step 3).
- **REF** (W4 camber -19.7, the shape path on new shifts): `z = |Delta_W4,V1 - 7.957e-3| / sqrt(SE_W4,V1^2 + (3.2e-4)^2)` against FID's V1 value (Halton 49-64; FID SE 3.2e-4 N); `CONSISTENT` if `z <= 3.5`, else `NOT_CONSISTENT` → `XV01_INVALID`; fewer than 12 pairs → `MISSING`.
- **Determinism**: the last case of kernel `v1_1` repeats the parent at 81 + (state `v18__parent__repeat`, the parent's bytes under its own name); both window means must equal the parent's at 81 + within 1e-12 N, else `NONDETERMINISM` → `XV01_INVALID`; a repeat that is invalid or missing leaves the check `NOT_JUDGED` (→ §5.9 step 3).
- The environment replays (§4.6) are preconditions of freeze 2; `ENV_DRIFT` (an install-guard failure of every remaining kernel after its rerun) is a kernel loss (`XV01_INCOMPLETE`, cause `ENV_DRIFT`); the closing replay is descriptive (`ENV_DRIFT_END`).

### 5.7 Export-resolution control EX (FID §6.6 form, for the finalist; outcome-relevant here)
Per V1 mirror pair `u_j = [pair mean of (F_r4(f) - F_r4(parent))] - [pair mean of (F_r8(f) - F_r8(parent))]` over the pairs where all four STLs are valid at both members (>= 12, else `UNRESOLVED_DATA`); `delta_EX = mean(u)`, `SE_EX` from the pairs; tolerance `0.1 |Delta_V1|` (r = 8). `EXPORT_INSENSITIVE` (→ PASS) if `|delta_EX| + 2 SE_EX <= tolerance`; `EXPORT_SENSITIVE` (→ FAIL, cause `EXPORT`) if `|delta_EX| - 2 SE_EX > tolerance`; else `EXPORT_UNRESOLVED` (→ `UNRESOLVED_STAT`). If the finalist's r = 4 STL fails X1 (P0), the r = 4 cases of both states are not built and EX is `UNRESOLVED_DATA` (cause `EX_EXPORT_FAILED`); this is fixed now, not decided after the export. FID found `|delta_EX|` of 6.0e-6 N against a tolerance of 8.0e-4 N (camber -19.7) and 3.1e-7 N against 9.8e-4 N (reflex -29.3). EX tests the export resolution of the same routine, not an independent geometry path.

### 5.9 Outcome (evaluation order)
1. **Invalid chain**: NC or REF `NOT_CONSISTENT`, or `NONDETERMINISM` → `XV01_INVALID` (causes `NC`, `REF`, `NONDETERMINISM`).
2. **Incomplete run set**: any registered formal kernel declared lost (§10) or not run (§4.4) → `XV01_INCOMPLETE` (causes `KERNEL_LOSS`, `ENV_DRIFT`, `BUDGET`), whatever the other data show; the resolved failures and passes that the available data would give are listed as descriptive would-be causes.
3. **Unjudged chain**: NC or REF `MISSING`, or determinism `NOT_JUDGED` → `XV01_UNRESOLVED` (causes `NC_MISSING`, `REF_MISSING`, `DETERMINISM_NOT_JUDGED`), with would-be causes listed.
4. **Resolved failures**: any `FAIL` among GAIN_V1/V2/V3, DRAG_V1/V2/V3, G1_V1/V2/V3, G3, G4, the V3 lower side, EX → `XV01_FAIL`; the cause list contains every applicable cause in this order: `GAIN_BELOW_FLOOR`, `DRAG_VIOLATION`, `XV_WL_OF` (G1 on V1, G4), `OF_MESH` (G1 on V2/V3, G3, the V3 lower side), `EXPORT`; with `DRAG_MATERIALITY` and `XV_OF_CORE` attached.
5. **Pass**: GAIN, DRAG and G1 on every level, G2, G3, G4, G5 (a, b as §5.4), both V3 sides and EX all `PASS`; NC and REF `CONSISTENT`; determinism judged and equal; no `FINALIST_ASYMMETRIC_LOSS` → **`XV01_PASS`**.
6. **Otherwise** → `XV01_UNRESOLVED` with the cause list: every `UNRESOLVED_STAT` / `UNRESOLVED_DATA` rule, `V3_ABOVE_BAND`, `FINALIST_ASYMMETRIC_LOSS`, `DATA_PARENT` (the parent below a level's minimum through physical case failures).
`XV01_UNRESOLVED (FINALIST_NOT_RUNNABLE_<level>)` is written instead when §4.6 ends the study before the formal run. Nothing in steps 1-6 is repaired from a value: no added shift, pair, level, state or extension round; no V3 removal; no rule variant per level or per pair.

`XV_OF_CORE` (secondary) = GAIN and DRAG `PASS` on every level, EX `PASS`, NC and REF `CONSISTENT` and determinism equal: it separates "the OpenFOAM improvement, the constraint and the export resolution hold on every mesh" from the WaterLily-fidelity and mesh-consistency rules, so that an outcome caused only by `XV_WL_OF`, `OF_MESH` or `V3_ABOVE_BAND` is legible. It changes no outcome.

### 5.11 Rule details fixed before freeze 1 (text-silent cases; extended by the reconciliation record)
1. A valid pair needs both mirror members valid for the state and the parent on that level and STL resolution; t uses the number of valid pairs minus 1.
2. NC and REF SEs are their own V1 pair SEs (no floor); EX needs >= 12 pairs valid for all four STLs.
3. Determinism compares both window means with |difference| <= 1e-12 N.
4. A completed, converged case with a non-finite window mean is an invalid case of the physical class.
5. G3 with `m <= 0` and V3 consistency with `mean_J d_V1 <= 0` are `UNRESOLVED_STAT` / `UNRESOLVED_DATA` (GAIN fails or is unresolved in these cases anyway).
6. Comparisons are in double precision without tolerance except item 3; `x_OF` is the literal of §5.2.
7. A kernel declared lost removes all its cases; `INCOMPLETE` at step 2 applies whatever the remaining data show.
8. Cause spellings and order are those of §5.9; every applicable cause is listed.
9. Any case that the text and the reconciliation record do not cover is resolved at analysis time by the reading less favourable to `XV01_PASS` (§10).

### 7.3 Reading
- **Three rules bind, not the gain floor.** Every GAIN_L passes with probability >= 0.94 in the reference scenario. What binds is (i) the confirmed drag non-increase on V3, (ii) G4 under selection attenuation and (iii) the V3 consistency band. They pull in different directions with the camber retention: a high V3 camber retention lifts the V3 drag and the V3/V1 ratio, a declining V1 camber retention fails G4.
- **Drag.** On the FID descriptive values the OpenFOAM drag retention of negative camber is high on V3 (camber -11.3: V1 0.56, V2 0.53, V3 0.92; camber -19.7: 0.84, 0.67, 0.84; below the G5b tested size, so FID reported but never judged them), while reflex -29.3 retains 0.69 / 0.62 / 0.59 and pitch +0.7 0.84 / 0.73 / 0.65 of its WaterLily drag. The model puts the V3 drag difference at about -1e-4 N, a small residual of large terms (camber +2.6e-3, reflex -3.5e-3, pitch +1.1e-3 N), and its pass probability moves from 0.10 to 0.85 when the reflex drag retention is scaled by 0.8 or 1.2: the sign is within model uncertainty, not a quantified prediction. This is the disclosure "drag neutrality relies on an untested OpenFOAM camber drag retention", made concrete. In a third of the reference replicates the drag rule is not passed while every level's upper bound stays below the L1 drag resolution (`DRAG_MATERIALITY`); §8.1 says how such a result is read.
- **Camber extension.** If the camber retention keeps declining with amplitude as from -11.3 to -19.7 mm (V1 0.77 → 0.61; a linear or quadratic extrapolation gives 0.42-0.54 at -29.55 mm), G4 fails almost surely and V3/V1 leaves the band; if it behaves like -11.3 mm, G4 and the band pass. The extension panel (§5.8) measures this at V1 for seven designs.
- **Stated pass probability.** Before funding, XV-01 states: the §5.7-implied probability is 1.00 / 0.80 for the gain floor and 0.94 / 0.30 for the G4 bound (central / pessimistic); the projected probability of `XV01_PASS` under the registered composed gate is **about 0.17 in the reference scenario and 0.00-0.35 over the structural scenarios, with model uncertainty of at least a factor 2**; `XV01_FAIL` (0.26-0.99, reference 0.49) is more likely than `XV01_PASS` in every scenario but one. The point value is not used for any decision.

### 7.4 What a non-PASS would still decide
A drag result measures, for the first time, the OpenFOAM drag retention of a camber-extension design whose WaterLily drag neutrality is a cancellation: the constraint-transfer question M4 (#66) needs answered. G4 and `EXT_V1_RETENTION` measure the selection attenuation and the extension fidelity at V1; the V3 rule measures the finest-mesh behaviour of the extension. §8.1 fixes what each outcome licenses. Every outcome is informative and the run set is the same for all of them.

## 10. Freeze, rerun, amendment and stopping rules (fail-closed)
- Order: §2. Freezes 1 and 2 and the written-once analysis are committed, pushed and commented on #65 before the runs they determine.
- **Kernel loss:** an attempt with any infrastructure status of §4.5 (classified against the frozen signature table; default physical/not infrastructure; one classification record per attempt). **One identical rerun per kernel** (same criteria bytes, same image); the first valid output is authoritative; both are archived. A kernel lost again is declared `--lost KERNEL=ID` with its criteria SHA-256 and both classification records; the analyzer refuses the declaration unless both attempts classify as infrastructure, and refuses to drop any kernel that has a valid output. Physical results (§4.5) are results, never a reason to rerun. No third attempt; a timeout is never raised after freeze 2.
- **Engineering defect found by a smoke, a replay or the probe before freeze 2:** fixed and re-frozen (an amendment of freeze 1 with diff and reason), then the affected smoke or replay is repeated once; rules, states, shifts and bytes never change; the endTime change of §4.6 is the only registered template change.
- **Amendment after freeze 2 (`REGISTERED_AMENDED`):** only for a defect that prevents a pre-specified quantity, filed on #65 before the analysis reads any force, never touching a rule, a state or a shift; the original outcome (or `INCOMPLETE`) is kept beside it.
- **Analyzer-defect protocol:** freeze 1 binds the synthetic-output tests of every §5.9 branch, the independent checker (written by a separate session from this text alone) and the reconciliation record of their pre-freeze cross-check (§5.11). At analysis time a discrepancy between analyzer and checker stops the write; the repair may only make the code match this text; the reading less favourable to `XV01_PASS` decides a case the text does not cover; the repair diff and both outputs are committed before the write. Any amendment reruns every branch test and records the diff.
- Stopping: one run set (§4.2), no stage repeated, no extension round, the §4.4 cap and limits, a second loss of the same kernel is final.
