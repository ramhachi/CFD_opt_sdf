## 1. What `min_feature_width` protects (from the code and the registrations)
- **Origin.** GEOM-02 plan (`docs/geom02_plan_2026_10_14.md`) item 1 and amendment A5; registration `sdf_topology_policy_v2_research_resolved_geom02_2026_10_14` (policy SHA `d4cd9aa4…`): `minimum_solid_width_m = minimum_void_width_m = 1.5h = 0.0375 m`, labelled **"lattice representability limit (research), not a physical or manufacturing minimum"**; physical/manufacturing limits stay unregistered and would be a new policy. Rationale in the plan: *a feature narrower than about two lattice cells cannot be represented or measured by the lattice width estimator*; 2h was rejected as circular (observed v16/v17 minimum). Guard h/4 from GEOM-01 v1: fail < 0.03125 m, unmeasured 0.03125–0.04375 m, pass > 0.04375 m.
- **Estimator** (`geometry_gates.min_feature_width_m`, reused by `geometry_gates_v2._feature_gates`): the registered V_phi cell occupancy (trilinear cell-centre value < 0, i.e. cell-wise binarisation), cropped to the solid AABB + 1 cell, repeated 4x per axis (no new information, only finer EDT sampling), Euclidean distance transform, ridge = voxels with EDT >= the 3x3x3 maximum (non-strict, so plateaus count), width = 2 x the smallest ridge EDT. Its own docstring: "not a guaranteed continuous-geometry minimum". Void width: the same on the complement inside the crop.
- **What consumes the geometry.** WaterLily sees the trilinear interpolant of phi (value and analytic gradient, `julia/CFDSDFWaterLily/src/GridSDFBody.jl`, `WaterLilyBody.jl`); the export surface is the Lewiner zero level of the r = 8 trilinear refinement (GEOM-02 profile). The cell occupancy is the V_phi counting rule (P22), not the shape the solver or the export sees.
- **Reading.** The gate is neither a manufacturing limit nor a flow-grid resolution limit: it is an SDF-lattice representability limit (thin sheets, fins, necks, slots that the h = 25 mm lattice cannot hold stably). Its sibling for SDF quality is `near_zero_gradient_band` (crossing slope), which fails one-cell sheets and tie plateaus separately.

## 3. Decomposition (descriptive)
- **D1 parent phase sweep.** The analytic parent (`v18_plate.plate_phi`, `genesis.json` parameters) on the v17 lattice with the origin shifted by (dx, dy, dz): dx, dz in {0..7} h/8, dy in {0..3} h/4 (256 phases; dy = 0 keeps the flat tips on the cell-centre plane).
- **D2 mode phase sweep.** Every non-parent MODE-01 v18 state (98) at 16 phases (dx, dz in {0..3} h/4, dy = 0), built as `v18_plate.mode_phi` on the shifted parent (analytic; the harness bytes differ by <= 2e-9 m). Phase 0 uses the gated harness bytes (`mode01_v18_prescreen.state_phi`): their phi SHA-256 and R0's status must equal the prescreen record for all 99 states (a mismatch invalidates the run).
- **D3 optimiser-like states.** 200 linear phi-space combinations of 2–3 proposed basis members, `parent + sum c_m (harness bytes at A*_m - parent)`, c ~ U(-1, 1), seeded; 50 more with U(-h/16, h/16) noise on the active nodes (a non-exact SDF). Registered lattice only (the optimiser does not move the lattice). This also measures how often R0 would reject optimiser candidates.
- **Per state:** each rule's value and status; R0 failure location (minimal ridge voxels classified in the parent plate frame: leading-edge round, trailing-edge round, flat tip, face); R4's defect on the R0 failures (the "one-cell nub" hypothesis: R0 failures whose occupancy defect is <= 1 cell); the analytic minimum thickness. If an R0 failure has an occupancy defect above one cell, the nub hypothesis is rejected for that state and it is listed.

## 4. Candidates (parameters frozen here)
All take only `phi` and h (any lattice state). Solid: an empty body is `unmeasured`. Void: no measurable void feature is `pass` (`not_applicable`, as GEOM-02 v2). Adoption of any of them needs a new content-addressed policy/profile and gate-contract version (the opening parameters are not policy fields today).
- **R1 SDF ridge.** The registered ridge rule applied to -phi (+phi for the void inside the solid AABB + 1 cell, crop boundary excluded) at the nodes; registered thresholds and guard. Reads phi units (not invariant to |grad phi|), misses tapers and hourglass necks (saddles); the crest is sampled at nodes (up to h |n|_max short).
- **R2 phase majority** (the task's "average over sub-cell phases"). R0 on 8 occupancies resampled at cell centres +-h/4 per axis; pass if >= 5 of 8 pass. Prediction recorded now: from 34/64 on the parent prototype it fails roughly half of the v18 placements (K1), because the 8 sub-samples are correlated; kept because the task names it. Worst-of-8 and best-of-8 are reported from the same values (stricter than R0 / a relaxation by construction).
- **R3 opening defect of the trilinear body.** B = {trilinear phi < 0} on the node-aligned h/4 refinement of the solid node AABB + 3 cells (B lies in cells touching a solid node; EDT ignores the crop boundary, so the margin creates no thin void). E = {x in B : EDT_B(x) > r}, r = 0.75h = half the registered 1.5h (strict: the fail-closed side of the +-h/8 quantisation); O = {x : dist(x, E) <= r}; D = max over B \ O of dist(x, O) (inf if E is empty). **Pass D <= tau = h, unmeasured D <= tau + h/4, fail beyond**, solid and void. tau from geometry only: a right-angle 3D vertex leaves (sqrt 3 - 1) r = 0.55h (a 2D edge 0.31h) and the refinement adds at most one voxel diagonal sqrt(3) h/4 = 0.43h; 0.98h rounded up to one cell. **What R3 tolerates by design:** material that no 1.5h ball reaches but that protrudes at most about one cell (short fins, bumps, short necks, wedges with full angle above ~51 deg). The registered rule rejects such features only at the placements where they show as an occupancy cell; the study reports this zone explicitly (class "short").
- **R4 opening defect of the registered occupancy** (the reviewer's "R0 after a one-cell opening", made fail-closed): R3's defect and thresholds on the 4x-repeated V_phi cell occupancy (crop AABB + 3 cells) instead of the trilinear body.
- **Threshold-only variants** are not candidates: R0 returns exactly one cell for a one-cell nub and for a one-cell sheet, so no threshold separates them (the synthetic slabs record the R0 values).

## 5. Controls
- **Synthetic (true widths known).** h = 0.025 m lattice of 26^3 nodes; phi at the nodes = signed EDT of the exact inside-predicate on an 8x refinement (error <= h/16). 16 draws per shape (uniform random rotation, uniform sub-cell translation; seed 20261020 with the draw index and the shape name). Shapes (in h): slab 8 x 8 x w, w in {0.5, 0.75, 1, 1.25, 1.5, 1.75, 2, 2.5, 3}; fin (6-cube + plate w x 6 x l), w in {0.5, 1}, l in {0.5, 1, 1.5, 2, 4}, and w = 3, l = 4; neck of length 4 between balls R = 2.5, d in {0.5, 1, 1.5, 2.5}, and d = 1 with length 1, 2; wedge (chord 8, span 6, full angle theta, capped at 5 thick) theta in {20, 40, 60, 90} deg; slot (block 8 x 8 x 7, through slot width g, depth 4, floor 3) g in {0.5, 1, 1.5, 3}; stadium plate (chord 12, span 6, flat tips) t in {2, 3, 4.6}; ball R in {1, 1.5, 2, 3}. A draw is scored only if the lattice holds the feature (at least one node of the right sign inside the thin part); the number not held is reported. Classes: **thin** = true width <= 1h and length >= 2h (slabs, fins l >= 2, necks of length 4, slots); **short** = thin width with length <= 1.5h (fins l <= 1.5, necks of length 1, 2): R3/R4's tolerated zone, reported; **thick** = true width >= 2.5h and convex radius >= 1.5h or sharp edges of at most 90 deg (slab 2.5/3, fin w = 3, neck d = 2.5, slot g = 3, stadium t >= 3, ball R >= 2); others transition (reported); wedges reported.
- **Axis-aligned slabs (K5).** Slabs spanning the lattice, w in {1, 1.125, ..., 2, 2.25, 2.5}h, 32 deterministic sub-cell phases each; R0's fail fraction crosses 50 % at a well-defined width (about 1.5h), unlike rotated finite slabs where R0 fails at every width.
- **Positive (smooth).** D1, D2, D3; the rev. 1 round-tip variant of the S0 probe (40 seeded rigid placements, round tips r = t/2 = 2.3h); R0 must reproduce the recorded width of each.
- **Historical.** All 77 OPT-01 v1 and 41 regen6p25 MODE-01 states and the 2 REINIT-04 outputs, rebuilt from committed code and checked against their recorded phi SHA-256 (state SHA-256 for REINIT-04) and recorded R0 status. Labels of the recorded width failures are assigned **before the run** from their documented mechanism: `rim_mismatch` (OPT-01 surge +-25: whole-cell shift with the end-plane layers pinned at the old outline; one lattice-congruent pair, the only expected fail), `tie_plateau` (also fails `near_zero_gradient_band`, the designated gate for random sign flips on a tie plateau), `thinned_slab` (thickness modes of the 2–3-cell slab, near the limit, no expectation), `broken_export` (REINIT-04: non-watertight export, negative volume; designated gates export/volume), `other`. The OPT-01 v1 parent is a 2–3-cell staircase slab, so most of these failures are the same occupancy mechanism as v18 at a smaller thickness; they are not "genuinely thin" by construction, and the synthetic suite is the primary negative control. The historical power is one congruent pair (disclosed).

## 6. Criteria (frozen) and choice
- **K1 artefact:** no non-pass over D1 + D2 (excluding states whose recorded phase-0 bundle fails a non-width gate: export/self-intersection or crossing slope; these are reported separately), D3 and the 40 round-tip placements. The flat tips are right-angle edges (radius 0), which the registered parent passes and every candidate must tolerate.
- **K2 thin:** no *thin* held draw passes.
- **K3 thick:** every *thick* draw passes.
- **K4 historical:** both `rim_mismatch` states fail; any other recorded width failure a candidate passes must still fail its bundle through another recorded gate (a pass with no other failing gate is a K4 failure); counts per label reported.
- **K5 not a relaxation:** on the aligned slabs, the candidate's 50 % width is >= R0's (zero tolerance).
- **K6 phi scale:** no thin held draw passes with phi doubled (R0, R2–R4 use only the sign of the trilinear phi and are invariant by construction; R1 is computed).
- **Choice:** among candidates meeting K1–K6, lexicographically (1) most *short* features not passing (closest to R0's strictness in the tolerated zone), (2) fewest new parameters (R1: 0; R4: 2, r and tau; R3: 3, r, tau, refinement; R2: 1, K). If none meets K1–K6 the result says so; no parameter is tuned after the run (a changed candidate is a new exploratory round with this one disclosed).

## 9. Execution deviations (recorded during the run, before any result was read)
- **2026-10-20 21:25, compute.** The first full run (9 workers, started 17:30) ran into machine-wide memory/IO thrashing from concurrent sessions (load average 80–190, swap 9.4/10 GB, ~40 % CPU idle); after 3 h 50 min it had about 850 of 3,242 tasks, with no per-task cache, and was stopped; its rows were never written or read. The rerun adds an append-only row cache (`work/width_rule_2026_10_20/rows.jsonl`, restart-safe), uses 5 workers, and evaluates **R2 (8 x R0, half of the per-state cost) only on D1, on phase 0 of every MODE-01 v18 state, on the round tips, the synthetic suite and the historical states**, not on the 1,470 D2 phases != 0 or on D3. R2's K1 outcome does not depend on this: the smoke run (`--limit 37`, before the first run) already showed the registered parent itself failing R2 at phase 0 (4 of 8 sub-samples pass), as §4 predicted. Rules, parameters, tasks and criteria are otherwise unchanged; K1 for R2 is computed on the rows where it was evaluated.
